# CreatorHub Agent 入口

本仓库的代码与实际运行状态优先。处理本工作区中的跨仓短视频发布任务时，如果同级存在 `../Haike-Videohub/agent-runbooks/README.md`，先读其索引、匹配的发布手册和相关契约，再核对本次用户授权、视频与封面文件、账号及任务实时状态。手册中的历史任务 ID 和界面步骤不是当前参数。

完成实际发布后，若发现可复用的新步骤、恢复方法，或旧手册与当前行为不符，按 Videohub 索引提交发现和证据；默认只提案。仅在用户明确委托维护知识库且核对证据后，才修改正式手册。普通问答和没有新发现的重复操作无需回写。独立克隆本仓库、且没有同级 Videohub 时，按本仓库文档和实时状态工作。
