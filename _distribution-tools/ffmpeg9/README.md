# Native Mac FFmpeg 9.0.2

The runtime manifest pins the original signed macOS binaries from [Martin Riedl's build server](https://ffmpeg.martin-riedl.de/) by archive and extracted executable SHA256. Both native build configurations enable GPL/version3 and libx264; neither configuration enables nonfree components.

- [Apple Silicon build configuration and library versions](https://ffmpeg.martin-riedl.de/download/macos/arm64/1789931890_9.0.2/versions.txt)
- [Intel build configuration and library versions](https://ffmpeg.martin-riedl.de/download/macos/amd64/1789931006_9.0.2/versions.txt)
- [Build scripts and dependency recipes](https://git.martin-riedl.de/ffmpeg/build-script)
- [Corresponding FFmpeg 9.0.2 source](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz)
- [Exact FFmpeg release commit](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b6dcd0331c8cc609192aeff5e1924f8)

The original FFmpeg license texts are retained beside this notice and copied into the native runtime. These are third-party GPL binaries; the project does not relabel them under its own license. Linked libraries retain their upstream licenses and source/build notices at the above release/build sources.
