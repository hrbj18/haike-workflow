# 海客视频可视化操作设计方案

日期：2026-10-13。本文件保留前版流程职责与视觉提案；用户已明确要求多模板、文案/声音/图片的同页生成入口，当前方案以同目录《多模板三项输入生成器.md》为准。尚未修改运行工作台或提交供应商视频生成。本方案围绕海客科技，延续已确认品牌和同一套固定导航。

## 目标与范围

用户只需在浏览器内填写内容、点选模板、人物和音色、试听、确认费用，即可跟踪制作并审看下载。无需粘贴供应商音色编号、理解云工作流或让 Agent 临时编写生产脚本。专业用户仍能进入现有片段工作台，逐段审核、替换画面和调整字幕。

当前配音页把服务状态、模型、音色编号、语速限制和角色绑定重复放在长卡片中；项目总览同时展示多条生产路径。改造重点是把操作收拢成连续流程，保留原功能的入口和真实业务条件。

当前入口统一覆盖圆框口播、全宽讲解、卡片讲解等已有模板，文案、声音和人物图片在同一页填写；各模板按真实适配状态开放制作。既有作品、音频、云任务和版本保留。以下分段解释各流程职责，不再要求用户逐页操作。

## 信息架构

桌面全局侧栏固定242px，唯一组件复用原 `navigation.js` / `navigation.css`。七个菜单及顺序保持：项目库、作品管理、配音中心、自动生产中心、已发布成片索引、素材库、素材解说。项目内步骤和编辑标签放在内容区；切换步骤只改变内容与选中状态，侧栏不重新排列。账户中心采用侧栏底部固定入口。

| 位置 | 用户看到什么 | 主要操作 |
| --- | --- | --- |
| 项目库 | 项目封面、制作阶段、最近结果、待处理提示 | 创建、继续制作、查看版本 |
| 项目制作 | 当前步骤、正文操作、模板预览、下一步 | 文案→模板→人物与声音→费用确认→预览下载 |
| 配音中心 | 紧凑音色目录、选中音色、常驻试听面板 | 选用、播放已有试听、生成新试听、管理自有音色 |
| 自动生产中心 | 现有批量规则和运行记录 | 配置批量任务、查看阶段、恢复 |
| 作品与片段 | 完整播放、字幕/画面/声音、版本差异 | 逐段审核、局部修改、下载 |
| 账户中心 | 可用余额、冻结额度、账单、Key、兑换码 | 注册登录、充值兑换、申请Key、查账 |
| 管理员后台 | 用户额度、供应商、模型费率、成本与利润 | 原有商业配置及运营管理 |

## 制作流程

### 文案

第一屏只有视频标题和正文两个主要输入，支持粘贴或导入现有Word。默认保留用户原文；“整理已有脚本 / 扩写想法 / 从零生成”作为主动选择，需要模型调用的动作独立报价。解析结果用可读的章节与台词展示，人物编号由系统生成；多角色脚本再显示角色映射。

草稿先保存，格式检查通过后才能进入下一步。字数、预计时长标明估算；实际时间线以最终音频为准。修改已生成的台词会提示影响范围，并建立新版本。

### 模板

缩略图使用项目内真实样片，点选可观看完整效果；展示名称、画幅、适用场景和可制作状态。模板3使用已确认的3:4卡片式讲解，保留白卡、柔和背景、圆框人物和章节摘要。模板选定后加载该模板允许的参数，不能把3:4合同直接当成9:16流程执行。

预览明确区分“模板样片”“版式示意”“已生成预览”。切换模板不删除已有版本。正式接入前模板3标记“样片可预览，制作接入中”，不提供假成功的一键生成。

### 人物与声音

人物用照片缩略图、名称和出镜效果呈现，支持选择已有角色或上传自有正面图。音色用名称、语言、声音特点和可用状态呈现，常用音色优先，未就绪音色折叠或禁用。

“试听”只播放已保存音频；不存在已有试听时，显示“生成新试听”，先展示报价再调用。短试听不是完整旁白，制作时明确标出需要生成的完整音频。已有完全相同、已绑定当前任务的产物，可以按合同复用；新任务不会因界面看起来相同而自动免计费。

语速集中在选中音色面板，腾讯等仅允许真实支持的档位；换声音时同时更新可选语速。初次选用可给默认值，音色编号、引擎、供应商及技术限制放入高级详情。角色图片和音色绑定一次保存，项目使用时固定本次输入快照。

### 费用确认与生成

确认页集中显示本次标题、模板、人物、音色、需要调用的能力、报价、预算上限、可用余额。用户价格按已生效费率显示；供应商成本和利润只在管理员侧展示。多步骤总价包含收费试听、正文配音、数字人和需要收费的其他调用，已支付项目与拟新增费用分列。

销售价格按成本×1.5：成本1元对应售价1.5元、毛利0.5元，收入毛利率约33.33%，未扣支付和服务器等费用。固定费率可精确报价；实际算力计费采用预算上限和完成后结算，不拿上一条数字人样片的0.264元当所有视频的成本。

报价绑定输入版本、费率版本与有效期，内容或配置变化后刷新。未定价能力显示“待配置价格”，阻止商业付费提交；余额不足提示兑换充值，返回后保留草稿。必须先完成统一网关接入才能承诺此页报价就是账户中心的实际扣款。

提交后禁用重复点击，返回同一任务。显示“排队→配音→数字人→画面/字幕→合成→待审核”；无数字人路径省略对应步骤。进度只使用后端已完成阶段与真实计数，无法预估时显示当前阶段和耗时，不编造百分比。用户关页后可以从项目库恢复查看。

### 审看与交付

生成完成进入待审核页面：完整播放器、章节列表、声音/字幕开关与修改入口。用户可选择片段检查字幕、发音和画面，局部调整另存版本。只修改字幕、卡片、位置或混音时走本地重合成，优先复用已确认媒体；台词、音色、人物变化需要重新生成的部分，重新显示对应费用。

下载预览与导出正式成片的状态分开。正式成片在人工确认后产生；对外发布继续使用现有独立确认流程。批量生产和高级片段操作沿用原有工具，不放进新手首屏。

## 配音中心的具体改造

桌面左侧为可筛选的紧凑音色目录，右侧为选中音色的常驻试听面板。目录行只保留名称、声音特点、语言、可用状态、播放和选用，避免每一行重复模型与语速长说明。已保存试听显示时长和来源；生成新试听显示输入框与报价确认。

普通用户看“选用音色 / 添加自有音色 / 管理人物绑定”；供应商凭证、模型上游路由和费率留在运营后台。独立本地部署保留专家配置入口，但商业接入模式必须由后端限制访问，不能只在前端隐藏按钮。收藏/筛选可作为轻量偏好，不改变可用性判定。

## 余额、Key和账单衔接

商业模式首次连接使用海客平台地址和用户自己的统一Key；供应商密钥留在后台。连接测试只检查身份、余额和能力，避免通过生成媒体验证连通性。Key设置掩码保存，不进入项目导出、版本文件或日志。

账户中心仍提供注册、管理员建号、额度充值、兑换码预览确认与Key管理。工作台显示可用余额/冻结额度，并提供账单入口；两个服务的登录状态和项目权限需要正式联接，不能仅凭同一浏览器打开就认为已经自动登录。

账单每项包含时间、项目/作品、任务、能力/模型、计费量、费率版本、金额、成功/失败/核对中、冻结与实扣。按项目、时间、模型筛选，进入调用详情能定位生成的版本。用户仅看自己的账单；管理员看供应商实际成本、售价和毛利。未知结果不当作失败退费，也不再次提交供应商请求，先核对原任务。

## 异常状态和恢复

| 状态 | 页面提示与动作 |
| --- | --- |
| 缺少图片、音色或有效脚本 | 指出缺项，跳回对应步骤；已填写内容保留 |
| 模型不可用或未定价 | 禁用提交，展示可行替代或联系管理员入口 |
| 报价过期/内容变化 | 刷新报价，重新确认新增费用 |
| 余额不足 | 展示缺少额度，跳转账户中心，返回继续草稿 |
| 排队/执行中 | 当前阶段、耗时、可离开提示；取消仅在后端允许时展示 |
| 网络中断或供应商结果未知 | 自动恢复状态查询；主操作“核对原任务”，不显示直接重复付费按钮 |
| 明确失败 | 展示失败阶段、可恢复动作及可能新增费用；完成步骤保留 |
| 页面或项目版本冲突 | 提示已有更新，加载新版本或保留副本，不静默覆盖 |

## 接口与当前能力核对

以下原生接口已在仓库定位；最终实现时仍须对照当前14754运行包合同，不能直接覆盖该运行包与仓库之间的历史差异。

| UI动作 | 当前接口/能力 | 接入要求 |
| --- | --- | --- |
| 项目详情与阶段 | `GET /api/project/{id}/workbench` | 用真实项目状态驱动步骤，兼容已有项目 |
| 脚本解析与确认 | `/workbench/avatar-script/imports/preview`、`/commit` | 先预览再确认；保留导入token和版本校验 |
| 音色目录和默认音色 | `GET /api/audio-center`、`PUT /api/audio-center/default-voice` | 选用不收费，可用性由服务端决定 |
| 新试听 | `POST /api/audio-center/previews/jobs` | 现有真实服务调用；新增商业报价/扣款联接 |
| 角色、图片与音色关联 | `/api/avatar-roles`、`/{role_id}/references/{slot}/file`、`/voice-binding` | 复用现有存储，补商业账户归属校验 |
| 审核预览与本地全片重合成 | `POST /api/production-queue/jobs` | 使用已注册的生产类型、父任务、幂等键和预算合同 |
| 状态、失败与恢复 | `GET /api/production-queue/jobs/{job_id}`及现有恢复接口 | unknown/ambiguous先查询核对；不自动重新付费 |
| 模板3参数化制作 | 原生VideoCompose / Remotion Atelier，已验证7秒短样片 | 尚需模板参数合同、3:4布局、章节数据、字幕和正式队列适配 |
| 统一Key与项目账单 | 已有独立API账户中心 | 原生制作链尚未全部切换到网关；需打通报价、冻结、供应商任务和结算关联 |

当前配音和数字人实测成功，模板3已完成短样片。账户中心商业测试40项通过，但“全部模型统一Key调用并自动扣入账单”尚未完整实测，数字人/文本的商业定价也仍有待配置项。设计不能把这些接入缺口显示成已上线功能。

## 实施顺序与验收

1. 选定视觉布局，做无真实扣款的可点击原型，覆盖文案、选择、报价、进度、失败和预览；固定导航复用既有组件。
2. 接入真实项目、脚本、角色和音色的读写；已有试听直接播放，收费生成仍通过现有明确确认流程。
3. 完成模板3参数化合同与原生统一队列适配，先复用既有7秒付费媒体验证本地预览和局部修改。
4. 连接统一Key、模型能力与费率、余额冻结、结算和项目账单；未定价能力禁用。最后在明确预算内验证一次真实端到端制作。
5. 扩展批量任务和其余已注册模板，沿用同一组件和状态机制。

验收：新用户不用Agent或终端就能完成制作；所有主操作可点击、可恢复；同一任务重复点击只有一笔供应商提交和一笔账单；已完成任务刷新后保持；未知状态不重付费；本地改字幕重合成不新增供应商任务；余额、冻结、实扣能对账；模板3实物预览和最终导出一致；侧栏切换位置不变；窄屏/键盘操作可用。
