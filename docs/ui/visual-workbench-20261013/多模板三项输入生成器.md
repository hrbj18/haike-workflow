# 海客视频：多模板数字人口播生成器

日期：2026-10-13。此方案是用户澄清后的当前入口设计，替代此前分步制作向导。用户已选本轮第3稿；源码位于 `prototypes/haike-avatar-generator`。实际14754项目库已增加“创建数字人口播”，同页进入 `/ui/avatar-generator/index.html`，侧栏可返回项目库；14757保留为开发预览。三项上传、音色读取、草稿恢复、样片播放及需求导出已验证。当前为交互设计页，真实生成/扣费待接。

## 用户只做四件事

**选择模板 → 上传/粘贴文案 → 选择声音 → 上传人物图片 → 生成。**

模板、文案、声音、图片放在同一个制作页面，不要求用户先学会分镜、字幕计时、模型配置或工作流。视频标题从文案/文件名生成，可在“更多设置”修改。用户提交后，系统负责音频准备、数字人、章节与画面编排、字幕和模板合成，最终返回可播放、可下载的待审视频。

全局侧栏沿用现有同一组件和七项菜单，尺寸与顺序不变。项目库的“创建数字人口播”入口已实现；项目内“继续制作”仍属于后续生产集成。用户无需切换配音中心、数字人素材、片段工作台等多个页面填写制作输入。

## 页面与操作

| 区域 | 展示与操作 |
| --- | --- |
| 模板选择 | 展示项目已有成片版式模板的封面、名称、画幅、适用场景和样片。点选改变选中状态，点播放观看真实样片；新模板从模板目录自动加入 |
| 文案 | 上传DOCX/TXT或直接粘贴。导入后显示可读正文，默认保留原稿；模板所需章节由后台组织，不要求用户逐段手工填写 |
| 声音 | 两种互斥来源：①使用音频：从自己的音频库选择，或上传WAV/MP3等支持格式；②选择音色配音：选音色、试听、调整支持的语速，提交后生成完整配音 |
| 人物图片 | 上传清晰正面照，显示缩略图、文件名和更换按钮；检测损坏文件、多人/无可用人脸、严重遮挡等问题，明确告诉用户如何更换 |
| 效果预览 | 展示所选模板真实样片或明确标记的版式示意；上传图片可展示裁切示意，正式口型视频在生成后播放，不能假称未生成的效果是实时成片 |
| 更多设置 | 默认收起：可修改标题、字幕、背景音乐、模板允许的配色等；人物布局、画幅与质量受模板合同限制，默认即可生成 |
| 主操作 | “生成数字人口播”先校验三项输入，再打开费用确认；“保存草稿”保留全部输入，不调用收费模型 |

**声音区的关键区别：**选择已有音频时直接使用它，不再额外生成TTS，也不额外收取TTS费用。文案用于内容结构及字幕，必须与音频中的口播一致；检测到明显不一致时返回具体段落，允许修正文案或更换音频。选音色时才按文案生成新配音，独立新试听也先确认费用。已有试听仅作声音参考，不能冒充完整正文。

切换模板保留文案、声音来源和图片，重新检查模板限制和报价。选择音色后切回已有音频，也不删除之前上传的音频。三个输入保存为当前草稿，上传完成有明确状态，处理中可离开并从项目库继续。

## 三项输入为何足够

人物图片加声音生成口型素材；文案负责讲解结构；模板提供布局、字幕、转场和内容画面的规则。模板1/2的主体素材、模板3的章节卡片都由后台编排，不再作为用户必填项。

需要动态素材时，按文案检索已授权的项目素材或允许的来源并选择合适区间；信息卡片按本期文本生成。无法找到可用素材或事实依据时，标明缺口，提供可用的讲解卡片替代或可选补充上传；不能用不相关画面硬凑。用户的图片默认是人物正面图，不能把一张人物图误当全部主体素材。

人物母版、音频、字幕和章节共享真实音频主时钟。上传音频不被变速去匹配模板；模板3的15秒/三章节示例不能写死成所有视频时长。已有视频换模板、改字幕等本地调整，优先复用该任务已完成媒体，只新增合成版本。

## 点生成之后

1. 校验选定模板、文案、声音来源和图片；检测音频时长、输入关联和可用能力。缺项定位到本页对应输入。
2. 展示此次要执行的付费步骤、用户售价、预算上限和余额。使用已有音频时列出“配音：使用已有音频”，不产生新的TTS收费；音频核验需要收费服务时也提前列出。
3. 用户确认费用后保存模板版本、输入哈希、费率版本与预算，提交一个可恢复的原生父任务。重复点击、断网刷新回到同一个任务。
4. 进度显示“排队 / 准备音频 / 生成数字人 / 编排画面与字幕 / 合成 / 待审核”，按所选来源省略不需要的收费阶段。进度来自实际事件，不编造倒计时。
5. 成功后播放完整视频，可下载预览、编辑内容或另存版本。重新制作前显示变化范围与新增费用；结果未知先核对原任务，不能重新付费提交。

销售费率继续按成本×1.5。各步价格来自后台已生效定价；数字人按实际算力结算时使用预算上限，不把上次短片的费用当固定单价。账户中心账单包含项目、模板版本、模型/能力、计费量、时间、冻结与实扣；用户查自己的记录，管理员查看成本和毛利。

## 实现需要的最小改造

**一个模板目录，三个输入控件，一个生成任务。**

- 模板目录统一保存稳定ID、版本、名称、画幅、封面/真实样片、所需输入、支持的声音来源、默认参数、制作可用状态和原生合成适配器。界面根据目录渲染，不再为每个模板单独写一套表单。
- 草稿保存：模板版本＋文案＋声音来源（音频资产或音色参数二选一）＋人物图片资产＋可选设置。上传绑定当前用户/项目；不信任前端传入的任意本地路径或其他用户资产。
- 为三种版式各自补正式适配器。模板2需要把临时脚本依赖移入正式模块；模板3需要把章节、时长和素材从源码常量改为数据。三种适配器复用同一人物生成、字幕和队列能力，预览/最终输出共享合同。
- 生成入口先调用可信预检和统一报价，再经已有生产队列调度。新增接口具体名称在实现时确定，此设计不声称已有一个完整的多模板生成API。
- 统一Key只用于海客网关，供应商密钥保存在后台。当前原生制作链与网关尚未全量打通，需完成余额冻结、供应商任务与账单关联后，才能承诺网页中三项输入直接完成商业扣款闭环。

## 验收与下一步

验收包括：三种模板正确路由；模板切换不丢输入；同一音频/图片在不同布局裁切正确；已有音频路径不调用TTS；音色路径生成完整配音；任意合规时长不受样片固定帧数限制；长文字幕不溢出；缺素材不假成功；重复点击不重付费；失败保留完成产物；成片可播放下载；账单可追溯到模板和项目。

第3稿已实现可点击页面，验收记录见 `prototypes/haike-avatar-generator/design-qa.md`。下一阶段先把模板3任意文案/时长改为参数化输入，再接资产、预检、统一队列及可信报价。首个真实验收复用已有音频与人物验证本地合成；付费端到端验证另在明确预算内进行。当前确认按钮保存本机制作需求，不提交真实生产任务。
