# 海客科技产品界面视觉规范

本轮以海客科技公司品牌为主体，统一海客视频工作台与 API 账户中心（含运营后台）。只调整呈现层，保留功能名称、路由、表单、事件与业务数据。

## 品牌与层级

- 统一使用手册第 4 页的官方「HAIKE + 海客科技」组合标志；产品名称单独展示在标志下方，不拼接或改画标志。
- 海客视频、海客导演台为内容生产工具；API 账户中心为额度、Key、模型价格与账单工具。公司识别一致，视频工具的全局入口使用固定共享导航。
- 标志从 PDF 原始矢量路径渲染为高分辨率透明 PNG，仅移除整页白色背景填充；保持颜色、笔画与比例。图片使用 contain，不拉伸、不加滤镜或阴影。

## 色彩与字体

| 用途 | 色值 | 应用 |
| --- | --- | --- |
| 活力橙 | `#F64B00` | 主要操作、导航选中边、标题分隔线 |
| 明媚黄 | `#FFDC00` | 余额重点、步骤编号、登录页品牌区 |
| 白色 | `#FFFFFF` | 导航与内容表面 |
| 标准灰 | `#A7A7A7` | 次要边线，不用于白底小字 |
| 黑色 | `#000000` | 品牌辅助色 |
| 手册辅助深红 | `#BA0901` | 可读链接与费用强调 |

主色依据手册 PDF 第 14 页；辅助色依据第 15 页。界面以 `#191919` 正文、`#666666` 次要文字、浅中性背景补充可读性。黑字/活力橙对比度 4.96:1，黑字/明媚黄 12.97:1，次要字/白底 5.74:1。

产品文字采用系统中文无衬线字体；手册未提供可用于网页的字体文件。标志文字直接使用原图，不以字体重绘。移除工作台 Google Fonts 远程请求，保持本地部署可用。

## 组件与状态

- 导航：浅黄选中底、橙色边、清晰黑字；使用同一套本地 Lucide 图标。全局入口固定为项目库、作品管理、配音中心、自动生产中心、已发布成片索引、素材库、素材解说。各页只改变选中状态，品牌文案、菜单顺序和几何尺寸一致。
- 项目内导航：导演台的总览、片段工作台、素材库、成片与版本，以及数字人项目专属入口，位于内容区顶部；保留原来的事件与显示条件。
- 按钮：橙色主要操作配黑字，悬停为明媚黄；次要操作为白底边框，危险操作仍使用原有危险状态。
- 表单：统一中性边线、圆角和键盘焦点；保留原有提示、选项、禁用条件与确认流程。
- 数据：金额使用等宽数字；可用、冻结、实扣分别展示，不改变已有计费语义。
- 卡片：白底、轻边线，标题优先于说明；保留成功、失败、等待等状态的文字与语义颜色。
- 登录页：使用手册第 18 页的黄色辅助底纹。工作区保留高密度信息，不添加营销模块。
- 窄屏：导航可换行或横向滚动，表单按单列排列，长表格保留内部滚动。
