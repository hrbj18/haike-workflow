# API 中转站用户名登录与简洁入口

已完成用户要求：登录和注册仅填写用户名、密码；取消邮箱格式、显示名称、确认密码和密码长度下限。用户名必填、去首尾空白并忽略大小写，支持中文及符号；唯一约束在数据库事务中保证注册与管理员开户不能重复。输入体积上限仍为用户名 120 字符、密码 128 字符。

沿用旧用户标识列，不迁移账户 ID、余额、平台 Key 或账单。请求支持 username 和历史 email 别名，name 仅作为旧客户端可选字段；返回 username 并保留旧 email 字段。旧邮箱账户继续用邮箱登录。管理员开户同样只需用户名与初始密码；重置及自行修改密码允许短密码，首次修改要求和会话撤销规则保留。

入口改为海客品牌的居中卡片，包含登录/注册切换、带图标输入框、密码显示按钮、主按钮、忘记密码入口。注册后自动登录，错误在表单内提示并聚焦相应输入；提交期间显示加载文字、禁用提交与模式切换。手机布局无水平溢出。充值指引、用户列表及 CSV 标签改用用户名。

验收：57 项 pytest 全部通过，Ruff 和 JavaScript 语法检查通过，根 scripts/check.py 通过。独立测试库浏览器验证中文用户名加 1 位密码注册、自动登录、显示密码、重复用户名反馈、模式切换、旧邮箱登录，以及手机入口布局。测试未操作真实资金、未调用付费上游。17894 本地服务已备份数据库并在无未完成任务时重启。
