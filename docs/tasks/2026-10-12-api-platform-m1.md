# 统一 API 平台 M1 本地实现

日期：2026-10-12。依据用户接受的 `docs/api-platform` 方案，在最新源码增加独立 `api-platform/` 本地服务。2026-10-12 再次用 SSH 查询远端 main，仍为 `05183670edca40483f4d2d212282e4c05c94cc84`。本次实现尚未提交或推送。

## 已交付

- 账户中心、管理员定价与核对页，支持首次自行设置管理员和普通客户注册。
- 密码 scrypt 哈希、HttpOnly 会话、同源/CSRF 写校验，随机客户 Key 哈希、一次性展示、预算、到期与撤销。
- SQLite 本地事务账本、整数微元与 Decimal 定价、模拟充值幂等、原子冻结与预算、不可变平衡凭证、钱包复算检查。
- 冻结价格与输入的报价、账户级请求幂等和持久化调用意图、outbox、持久化提交编号、模拟任务结算/释放与未知提交核对。
- 模型/状态筛选、准确用量与精细费用、任务详情、CSV 导出，管理员草稿/发布与版本保留。
- 单 Key Agent 客户端私有配置、费用上限、持久化请求编号、重复恢复与更换 Key。
- Mac/Windows 启动入口、无外部 CDN 的网页和 API 接入说明；完整实现协议由运行服务 `/openapi.json` 生成。
