# API 中转：统一 Key 与 1.5 倍明细计费

实现位于 `api-platform/`，本地服务 `http://127.0.0.1:17894/`。原账户数据库已私有备份并保留，升级未提交真实付费任务。

- 用户端仅余额充值、API Key、调用账单。一个平台 Key 使用全部已开通能力，新模型无需重新申请 Key；商业冻结与月消费单独统计，月份按上海结算时间。
- 管理员可新增 OpenAI 兼容平台、添加文本/视觉模型映射、调整路由与开关。新增平台默认关闭。需要采购价、已发布价格和渠道/模型开关同时开启才能接收调用。专用配音、识别、数字人与素材继续使用内置适配器。
- 新发布的真实价格强制成本 × 1.5、零附加服务费；旧报价、模型信息、计量单位及渠道/上游型号保留快照，已提交任务沿用旧版本。
- 账单逐项列出实际计量、固定售价、金额，合计仅舍入一次；舍入调整、超出费用上限减免、释放金额及本次凭证可核对。用户只能查看自己账户；上游密钥不回显，采购单价与毛利仅后台返回。
- 调用账单导出遵循当前模型/状态筛选，另支持账户资金流水与管理员运营 CSV；导出上限 500 条，电子表格公式转义。

自动验收：44 项 pytest 通过，覆盖同一 Key 跨两个上游、路由与价格快照、余额不足、幂等、精度舍入、费用上限、释放、模型暂停、权限隔离、CSV 和旧流程回归。Ruff 与前端 JS 语法检查通过。使用 Python 3.12 运行根 `scripts/check.py`，2929 个文件/1058 个 Python 文件源码检查通过。

浏览器验收使用独立 `api-platform/output/playwright/unified-20261013/test.sqlite3` 和假供应商，检查用户三菜单、统一接入信息、Token 分项、凭证、管理员渠道配置与桌面/390px 手机布局。匿名 me 请求的 401 属预期；有字段名冲突的新增渠道表单已修复，并增加 POST 提交避免凭据进入地址栏。

真实上游渠道、供应商费率/账单及真实支付仍需要单独验收。新增平台只支持非流式 OpenAI 兼容 Chat Completions；当前服务仍只监听本机，充值为管理员入账或兑换码，没有微信/支付宝收款回调。

## 模型卡片直接接入

按后续要求，模型卡片「前往接入」改为按模型选择相应供应商，直接填写 API 地址和平台密钥，不再跳到 JSON 调用试用页。表单显示该模型的采购单价、调用售价和计量单位，音色、上游型号、工作流等收进高级设置；腾讯云用 SecretId / SecretKey。已保存密钥留空保留，保存后保持模型列表；待定价档位可打开同模型定价表单，系数固定 1.5。上游配置仍需管理员权限，普通用户仍使用平台统一 Key。

复验：44 项自动测试通过，Ruff/JS 语法检查通过；独立数据库浏览器检查文本双 Token 单价、CosyVoice 万字符售价、密钥留空保存保留、腾讯双密钥和手机宽度、待定价模型关联价格表单。价格表在手机视口取消通用表格最小宽度，使单价直接可见。未使用真实密钥或发起付费调用。

## 浏览器返回与前进

站内页面使用 `?page=页面编号` 写入浏览器历史，首次进入替换当前记录，页面切换新增记录，同页刷新或表单保存不新增记录。浏览器返回/前进按照地址恢复页面并关闭旧弹窗，刷新后恢复当前页面；登录会话保持不变，页面权限继续按账户角色检查。浏览器离开最早的站内记录后仍按正常历史返回外部页面，不拦截用户离站。

本次验收：JS 语法检查通过；Playwright 在独立测试服务验证余额→API Key→账单、逐级返回、前进、刷新恢复 API Key、重复菜单不增加历史，以及持续登录状态。刷新后的浏览器控制台无错误。真实账户数据未修改。
