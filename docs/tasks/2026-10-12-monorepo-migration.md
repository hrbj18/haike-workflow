# 单仓库整理与上传

目标：将现有四仓工作区的当前源码整理为一个可维护的私有 GitHub 仓库。

范围：四模块源码、必要配置模板、正式测试、操作手册、统一安装/检查/源码打包入口。保留既有目录深度；保留原工作区与 Git 历史，不改变运行服务。

排除：凭据、Cookie、浏览器状态、数据库、真实项目、私人媒体、模型缓存、依赖环境、历史 Git 元数据与旧二进制发行包。第三方模块不追加统一开源授权。

实施：按文件清单导出当前文件（含未提交功能），检查配置和候选文件，新增单仓库安装/验证工具，记录来源版本和文件哈希。在新目录初始化 Git，审查暂存区后创建私有远端并推送。

验收：无嵌套 gitlink；凭据扫描通过；文件清单核对通过；Python/PowerShell 静态检查通过；跨模块契约和迁移工具测试通过；从提交生成独立副本复核；GitHub 远端提交与本地一致。源机器上的检查不宣称为另一台物理机、真实账号或云服务验收。

安全边界：不启动采集/发布/生产，不调用付费服务，不导入私人凭据，不改变原工作区。可选本地 TTS 默认跳过。现有业务回归若失败，记录具体边界，不隐瞒为全量通过。
