# 海客工作台共享导航

需求：各页面菜单使用同一组件，切换入口时保持品牌区、菜单顺序和侧栏尺寸一致，保留原有功能。

## 实现

- `Haike_video/backlot/ui/navigation.js` 是七个全局入口的唯一定义；静态页面挂载占位，导演台通过 `getGlobalSidebar()` 复用节点。
- `navigation.css` 最后加载，以组件作用域隔离各页原有 nav/aside 样式。桌面固定 242px；窄屏使用统一网格，选中项字重不会改变菜单位置。
- 路由决定 `aria-current`。项目详情和旧版看板属于项目库，素材管理属于素材库；配音中心保留返回项目参数。
- 项目内标签移到内容顶部，保留总览、片段工作台、素材库、成片与版本，以及数字人项目原有入口与事件。
- 源仓库和已解压运行包分别应用补丁，保留两者原有功能差异。

## 验证

跨页点击与矩形一致性：七个入口 × 四种宽度；项目标签节点复用：四个标签 × 三种宽度；另检验深色主题、素材管理与旧版看板。操作 ID 与业务脚本引用对照通过，源码与交接检查通过。

测试范围与截图见仓库根目录 `design-qa.md`。测试脚本、输出与本轮备份位于忽略目录 `output/playwright/`。未调用付费模型、生产媒体或操作实际业务数据。
