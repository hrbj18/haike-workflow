# 海客 API 账户中心：商业额度与统一网关验收

本地服务为 http://127.0.0.1:17894/ 。保留原管理员与原数据库，运行版本 0.2.0。默认售价采用用户确认的「成本 × 1.5」，每次附加服务费为零。

## 已实现

- 客户自助注册；管理员创建客户、充值并留存入账凭证。
- 兑换码额度预览、一次领取、有效期、可选账户绑定、撤销与批量生成。
- 客户一个平台 Key 调用六种能力，设置预算与有效期；供应商密钥保存在服务端加密私有目录。
- 供应商配置、价格与毛利试算、确认成本后发布不可变价格版本。
- 用户查看调用用量、冻结、实扣、供应商编号和结果，导出调用账单；管理员查看客户收入与估算成本/毛利。
- 免费报价、费用上限确认、幂等提交、异步编号恢复、未知提交人工核对；供应商超出报价的成本不追加扣客户。
- 标准库客户端与项目命令 `Haike_video/scripts/haike_api.py`，已同步至原本地安装目录；未复制供应商密钥或后台数据库。既有生产队列仍按原供应商设置运行，统一接入通过这个新入口使用。

## 验证结果

- 33 项自动测试通过，覆盖账户隔离、充值并发、兑换码领取、价格冻结、余额与每日预算、供应商回执、提交响应丢失、服务重启、人工核对及双 Token 计量账单导出。
- Ruff 检查、前端 JavaScript 语法检查通过；项目源码检查 2844 个文件、1056 个 Python 文件通过；上下文交接文件长度审计通过。
- Playwright 使用独立数据库和假供应商验收自主注册、管理员开户、充值、兑换码发放/预览/领取、Key 创建、报价、提交、用量结算与账单详情。
- 管理员定价页面实测成本 ¥0.80 → 售价 ¥1.20 → 毛利 ¥0.40（毛利率 33.33%），发布新版本；既有任务账单保留旧价格版本。
- 配置页面不回显密钥，空密钥保存保留原值；管理员运营账单显示对应客户；普通客户仅显示五个客户菜单。
- 桌面账单/运营页、390px 手机账单弹窗无页面横向溢出；控制台未发现未捕获 JavaScript 异常。首次匿名访问账户信息产生预期的 401。
- 测试工件位于 `api-platform/output/playwright/`，测试数据均为独立假数据，未消耗真实 API 额度。

## 待真实账户验收

五个供应商凭据已导入，四个档位已按公开成本基准配置 1.5 倍售价。中转 GPT 与 RunningHub 工作流缺少实际采购价，保持待定价；填入采购成本、来源、计量单位并确认后可发布开通。真实密钥、音色权限、模型结果与采购账单尚未进行付费连通验收。

当前支持管理员入账与兑换码，未接微信/支付宝在线收款。公网销售与生产部署边界见 [商业额度与统一网关](../api-platform/商业额度与统一网关.md)。
