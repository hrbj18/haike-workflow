# 三套动效模板交付与维护

本轮目标为科技控制台、深色立体多屏展陈、活力海报三套可编辑模板。实际版本、样片、包大小与通过范围以交付目录的验收记录为准。新模板仍从统一动效模板工作台创建，整片由统一队列执行；不直接拼接旧成片作为新验收。

科技控制台使用原生竖屏重排后的4:5视窗，人物默认只在开头放大出镜。深色立体采用项目4:5重排，并支持开头、结尾或隐藏人物。活力海报采用原包公开控件的4:5重排，默认不出镜，以完整旁白讲解照片与实拍。三套均以完整音轨为时钟，替换文案、素材和人物后重新审核本期画面。

交付的三个`.motion`文件是用户自己的原始模板文件，保留各自包版本和摘要。项目适配器、命名变体和原始包分别保存；原包本身不等于项目已经完成适配。私人原包与示例媒体只在本地交付，不进入公共源码包。具体可编辑字段来自每套profile和工作台表单，未开放的颜色、几何和动作不能通过填写无效参数修改。

## 首次部署与日常更新

已有的完整运行环境可通过本地介质复制一次，换目录后先执行`01-setup.cmd`。离线准备重定位三套模板的受控素材与证明、Python环境及包登记路径；不安装npm、pip或FFmpeg。然后执行`03-check.cmd -Full`核对分发文件及运行依赖，再双击`02-start.cmd`。空白电脑仍需要这份首次运行环境，单独源码不能替代Python、Node、FFmpeg及浏览器。

日常程序更新在“关于海客视频”选择本地更新ZIP，核对目标版本后安装；更新会等待现有任务结束、备份、重启并检查启动结果。兼容更新ZIP与清单总计不超过300,000,000字节；包含变更源码、预编译界面和可分发适配资源，保留配置、私人模板、素材、草稿、命名变体和作品。运行环境或数据结构不兼容时拒绝小包，需要单独安排环境升级。

私人素材的迁移清单只允许生成本安装`.local/<模板>/assets`中的受控JSON，先校验全部引用后写入；文件身份不符时停止，不猜测替换。原包登记只重绑定本安装中摘要一致的包与固定官方helper。已声明离线依赖的模板使用随首次部署保留的缓存，缺失时应报错，不后台下载大依赖。

## 验收与恢复

每套必须在本轮安装中通过实际源帧、编排与最终预览检查，保存命名变体并读回，再实际导出。验收核对1440×1800、60fps、至少20Mbps、完整帧数、AAC48k双声道、完整解码与实际编码画面。技术、视觉抽样、连续听看、物理新机和用户确认分别记录，不能相互代替。

更新验收包括连续兼容升级、配置和旧作品保留、损坏及不兼容包拒绝、启动故障自动回滚。换目录测试应使用独立安装、独立服务端口及自己的素材/依赖路径，不能以开发目录仍可访问证明迁移成功。另一台物理机的结果以实际执行记录为准。

失败时保留原任务、输入、预览和更新备份。渲染只恢复原队列编号；已成功的口播与数字人不重新付费生成。程序回退不代替私人媒体和生产数据备份。线上更新清单与视频发布需另行授权，本地包验收不代表已公网发布。
