# 海客视频 v1.0.0

2026-10-28，首个带统一产品版本和在线版本检查的正式发行版。

## 交付范围

以稳定源码 `b1ac99691060349b9700e7e014d3effde820db3b` 为基线，仅加入本轮应用更新功能与发行工具。其他开发窗口尚未提交的视频模板、编辑器、渲染和供应商改动未纳入本版。

- 工作台底部“关于海客视频”显示产品版本、构建提交、安装类型和模板补丁。
- 从固定 GitHub Release HTTPS 清单检查稳定版本；本地版本读取失败与网络检查失败分别提示。
- Windows x64 便携安装支持匹配基线、运行环境和数据版本的程序补丁；安装前保存草稿并等待现有任务，下载/等待阶段可暂缓。
- 独立助手验证 SHA256、备份程序、重启并检查；安装或启动失败恢复原程序。配置、平台账号、Cookie、项目、素材和作品不纳入更新覆盖范围。
- 源码副本保留开发状态，不自动覆盖本地修改；发布、采集及云端收费服务代码不随程序补丁升级。

## 首次安装与更新

下载 Release 的 `haike-video-v1.0.0-windows-x64-online.zip`，核对 SHA256，解压到新目录。双击 `01-setup.cmd` 从国内可直连源安装依赖，导入自己的私有配置后运行 `02-start.cmd`。下载地址、重试和可选资源见 [联网安装说明](../ONLINE_INSTALL.md)。包内不捆绑虚拟环境、Node、渲染浏览器和大模型；Whisper、Qwen 默认不下载。

本版完整程序包是后续补丁的 v1.0.0 基线，旧版安装需要先完成迁移，不能当成补丁覆盖运行目录。

首版 `haike-update.json` 明确标记 `package.kind=full`。已装 v1.0.0 会显示当前版本；更旧安装提示完整迁移。后续兼容补丁清单使用 `patch` 类型，由补丁构建器生成。

## 分发与验证边界

公开附件不带 Key、Cookie、账户数据库、私人截图/样片、人物、声音、任务或作品。现有40张仅获本地交付授权的模板截图保持原交付范围。MediaCrawler仍为可选依赖，按原许可单独配置；不捆绑本地 Qwen TTS。

验证包括源码与凭据边界、版本/更新接口、前端构建、隔离升级与回退、用户数据哨兵，以及便携初始化和诊断。本机隔离验证不代表另一台物理机、真实账号、付费生产、发布或资金结算已验收。

源码提交以 Git 标签和包内 `RELEASE.json` 为准，文件校验以包内 `PACKAGE-MANIFEST.json` 及 Release SHA256 为准。故障恢复见 `docs/APP_UPDATES.md`。
