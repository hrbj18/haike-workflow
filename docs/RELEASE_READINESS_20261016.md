## 交付边界

本机内部试用与“新电脑仅填海客Key即可完整商用”分别验收。后者目前仍不能宣称完成：

1. 云端账号音色接口的发布与真实克隆验收未完成；私人声音映射仍是本机内部备用路线。上线情况须按正式部署复验。
2. 实际模板菜单确认ADu动效引擎未安装；基础安装没有自动安装该独立依赖。MediaCrawler另外是可选学习运行时，商用许可门禁继续保持。
3. 干净新电脑完整安装、隔夜/系统重启登录、真实目标平台发布尚未完成本轮验收；既有数字人调用费用回执仍待核对。
4. 当前迁移源码尚未冻结提交，标准打包器只导出干净HEAD；不能把旧HEAD源码包称为本轮新版交付。

三条真实下载链及快手/视频号冷重启结论沿用2026-10-16既有脱敏证据，本轮不重复付费、登录验证或下载；离线回归不能替代平台后续风控与外部服务验收。详见 `COOKIE_SESSION_PLAN.md` 与 `PRODUCT_YBW_MIGRATION.md`。
