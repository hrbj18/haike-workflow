# 科技控制台本机交付与更新

本期范围：Windows x64、科技控制台原包 2.7.20-alpha.3、4:5 输出。本机独立安装位于 `D:/codex_work/HaikeStable`，工作台端口 14758；源码工作区与实际安装分开。具体成功项以随交付提供的本机验收记录为准，不代表第二台物理机或云服务已经实测。

## 日常制作

从动效模板工作台创建科技控制台视频，修改画面文案、六路视频素材、配乐及人物出镜方式。4:5 新视频默认仅开头出镜；可选仅结尾或隐藏，旧项目保留原来的布局。人物开头最多显示首场景的五秒，结尾最多显示末场景的五秒。人物层使用同一段已经生成的口播帧，完整旁白继续播放。

先检查素材和人物帧，再检查本期编排与最终视窗预览，审核后提交统一生产队列。修改后重新预览，不沿用旧版本审核。预览审核后可保存命名变体，后续从变体创建视频。变体保存布局和文案，不自动继承上一条付费生成任务。已有口播可通过“复用已完成口播源”使用，避免重复生成。

出镜控制属于项目自己的制作扩展，原包没有对应的 native 开关。官方有界预览先生成原生工程，再由项目画面层按同一时钟捕获出镜调整；界面分别标注原生对照与调整后的交付画面，全部检查后冻结摘要。统一队列使用同一画面层导出，并保留官方原生声音。不修改原始 .motion 或原生 HTML；需要检查完整成片，不能以静态预览代替运动及声音审核。

## 一次部署，后续小包更新

首次部署需要完整运行环境：Python、Node、FFmpeg、浏览器和固定依赖。可以从已经准备好的本地交付介质复制；空白电脑不能只靠源码运行。首次部署体积不计入日常更新限制。

日常在工作台“关于海客视频”中选择本地程序更新 ZIP，检查显示的基线与目标版本，保存当前编辑后安装。更新器等待运行任务结束、备份程序、安装并重启，启动检查失败时回滚。安装副本不运行 Git 拉取、npm ci 或 pip install。更新包包括变更源码、预编译前端和可分发模板资源，ZIP 与版本清单合计不得超过 300,000,000 字节。

配置、账号、私人原包、缓存、草稿、命名变体和作品不进入公开更新包。原包的私人标识仅存本机；不要把 `.local` 或项目素材复制进公开仓库。发布更新包不等于发布视频，Git 推送也不等于部署。

兼容更新要求 edition、platform、runtime_id、data_schema 以及依赖锁定一致。依赖或数据结构不兼容时，更新器应拒绝小包并保留旧版；需要单独安排运行环境升级，不能承诺所有未来版本永远不更新依赖。

## 维护验收

发布前必须检查包大小与 SHA、源码检查、相关回归测试，以及同一安装的连续升级。每次升级后检查版本和服务身份、配置与变体保留、旧视频可读，并在新版本实际生成样片。损坏包、不兼容包应在修改程序前拒绝；有效包导致启动失败时，应恢复旧程序和服务。生产数据的保留另行核验，不以回滚程序替代数据备份。

本地更新包可直接交付使用。在线更新地址只有在另行完成发布后才可使用；本次本地验收不证明网络发布成功。
