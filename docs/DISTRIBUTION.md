# 交付边界

## 上传内容

四模块当前源码、正式测试、配置模板、通用布局与视频模板、技能文档、跨模块契约和正式手册。根目录管理统一安装、检查、源码打包与 CI。Git 源码和便携 ZIP 分别交付；根目录含 `PACKAGE-MANIFEST.json` 的便携包以 [PORTABLE.md](PORTABLE.md) 为初始化入口，海客 Key 与扫码说明以 [API_KEY_SETUP.md](API_KEY_SETUP.md) 为单独交付源文件。

初次导入含源工作区未提交改动，SOURCE-PROVENANCE.json 保存原 HEAD、分支以及原始文件哈希。它是导入追溯记录，不用于断言后续文件仍与原工作区相同。后续版本以单仓库 Git 提交为准。

## 排除内容

Git 源码排除 Cookie、API 密钥、浏览器会话、账号数据库、真实项目、历史任务、素材与成片、私人音色、曲库、虚拟环境、node_modules、大模型、运行时二进制、缓存、日志、备份、一次性排障与排期脚本，以及原仓库 Git 历史。原工作区保持原样。

便携 ZIP 在干净源码基础上另行加入声明的运行时、依赖、浏览器、通用模型和前端产物；具体内容以包内清单为准。包内仍排除所有用户凭据、账号和浏览器会话、私人媒体/音色、历史任务、账本与运行数据；首次启动再建立本用户私有配置。前端从干净源码构建，私人预览图片（含 `presenter.png`）不进入 public 或产物，不直接复制日常工作区的 dist。

MediaCrawler 继续作为按需获取的第三方依赖。小型 YuNet 模型使用固定提交下载并校验哈希；字体与原有代码许可证保留。便携包只纳入已核对分发声明的依赖，缺少的可选能力按初始化诊断处理；旧发行包不混入源码。

## 版本维护

所有修改从仓库根提交。模块的上游地址只表示来源，不能在模块目录内 pull/checkout 上游以覆盖本版本。Haike-Videohub/contracts/versions.json 中的旧四仓状态仅作为历史材料；当前导入版本见根 SOURCE-PROVENANCE.json。

## 发布范围

用户于2026-10-17确认沿用公开仓库 `hrbj18/haike-workflow`，源码上传使用新版独立分支和旧版保留标签，不修改 main。该阶段“不打包”是历史范围；当前已另行授权制作完整便携 ZIP 和独立 API Key 配置说明。Key、Cookie、私人媒体和运行数据排除在新增提交及交付包之外。

Haike 的 AGPL 原文以及各组件已有声明保留；根目录不为所有代码追加统一开源许可证。组件及外部资源继续遵循各自分发声明，仓库可见性不替代许可核对。初始化和隔离诊断通过只证明本次包的对应检查通过；云端能力、真实账号和另一台物理机的完整制作/发布须分别核验，本次打包不发起真实付费制作或发布。
