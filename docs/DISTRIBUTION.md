# 交付边界

## 上传内容

四模块当前源码、正式测试、配置模板、通用布局与视频模板、技能文档、跨模块契约和正式手册。根目录管理统一安装、检查、源码打包与 CI。

初次导入含源工作区未提交改动，SOURCE-PROVENANCE.json 保存原 HEAD、分支以及原始文件哈希。它是导入追溯记录，不用于断言后续文件仍与原工作区相同。后续版本以单仓库 Git 提交为准。

## 排除内容

Cookie、API 密钥、浏览器会话、账号数据库、真实项目、历史任务、素材与成片、私人音色、曲库、虚拟环境、node_modules、大模型、运行时二进制、缓存、日志、备份、一次性排障与排期脚本，以及原仓库 Git 历史。原工作区保持原样。

MediaCrawler 继续作为按需获取的第三方依赖。小型 YuNet 模型改为固定提交下载并校验哈希；字体与原有代码许可证保留。旧便携包构建器依赖本机环境，本仓改用可复现的已提交源码 ZIP；不把旧发行包混入源码。

## 版本维护

所有修改从仓库根提交。模块的上游地址只表示来源，不能在模块目录内 pull/checkout 上游以覆盖本版本。Haike-Videohub/contracts/versions.json 中的旧四仓状态仅作为历史材料；当前导入版本见根 SOURCE-PROVENANCE.json。

## 发布范围

本次创建私有仓库用于用户授权的源码备份和维护。Haike 的 AGPL 原文以及各组件已有声明保留；根目录不为所有代码追加统一开源许可证。CreatorHub、CopySkill、部署中枢及外部资源的公开分发授权需逐项核实，私有保存不代表已取得对外再分发许可。
