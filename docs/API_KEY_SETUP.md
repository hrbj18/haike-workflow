# 海客 API Key 与首次配置

本说明可单独交给新用户，也随便携包保留。先完成便携包的 `01-setup.cmd`，再用 `02-start.cmd` 打开工作台；源码安装按根 README。工作台默认端口为 14756，账号服务默认端口为 8000，实际地址以启动结果为准。

## 1. 填写自己的海客 Key

1. 从海客账户中心取得自己账户的 API Key，并确认可用额度。账户中心默认地址为 `https://8.138.207.71:17894/`；服务方提供其他地址时使用其地址。
2. 在工作台打开“API 设置”→“统一 API 接入”。“网关地址”填写 `https://8.138.207.71:17894/v2`，或服务方提供的完整 `/v2` 地址；在“API Key”粘贴自己的 Key。
3. 点击“保存并测试连接”，确认“连接正常”、可用额度和“模型能力”。连接检查只查询 Key、额度和已开通能力，不产生制作费用。
4. 通过“管理我的音色”读取当前账户音色。需要合成配音时，选择本账户实际可用的音色；新机器没有原机器的私人音色。

Key 保存在本机后台私有配置，保存后不会回显。向 Agent 提供“已配置/连接失败”等结果即可；聊天、报告、截图和批次规格都不需要完整 Key。通过 CLI 配置时也要明确填写网关地址，不能沿用其他工具的本机地址默认值。

## 2. 三个平台分别扫码

在“API 设置”下方的“平台账号”中，依次打开抖音、快手、视频号的“管理登录”，选择平台并扫码，按页面提示完成手机确认或平台验证。登录记录只保存在这台电脑；另一台电脑需要自己的登录。

登录后点击“检查登录状态”，分别查看素材与“视频发布”的状态。绿灯“最近检查正常”表示最近 8 小时有成功检查记录；素材搜索、下载和发布前仍会再次验证。黄色表示待确认，红色“需登录”表示平台明确要求重新登录。素材状态和发布状态分别判断。

当前关键词素材搜索接入抖音；快手和视频号提供分享链接下载及发布能力。抖音关键词搜索还需要可选采集环境、Chrome 路径及适用的授权配置；扫码成功不能代替这些条件。联网素材/AI 分镜目前还需要独立的 OpenAI 兼容中转配置，见第 5 节。开启“联网搜索画面素材”后，找不到合适画面会明确暂停、等待补充素材。

## 3. 选择输入路线

| 用户提供的材料 | Agent 和工作台怎么做 | 必须具备的能力 |
| --- | --- | --- |
| 一张人物图＋一段完整口播录音＋制作要求 | 直接用完整音轨驱动数字人，由 Agent 整理对应文案、标题和版式 | 数字人口播、字幕识别；无需先克隆声音或合成配音 |
| 一张人物图＋声音样本＋一句主题要求 | Agent 先写实际口播稿，配音中心克隆或选择音色，再合成新配音、生成数字人和视频 | 云端音色/样音上传、声音克隆、配音、数字人口播、字幕识别 |

人物图使用自己有权使用的 PNG/JPEG，宽高至少 256 像素、文件不超过 20 MB。完整口播录音支持 WAV、MP3、M4A、OGG，数字人路线最终音轨不超过 120 秒。声音样本用于克隆，建议准备 5 至 60 秒的清晰单人讲话 PCM WAV；它不能当作完整口播音轨。

一句主题要求由 Agent 整理成稿件，也需明确本次模板/时长、预算和是否联网取材；已有账号预设可直接复用。当前批次 CLI 接受“稿件＋音色”路线，完整录音使用工作台已有音频入口。人物图精修是单独的可选报价项目，可按需要选择。

## 4. 让 Agent 接手和夜间执行

把解压目录交给能在本机读取文件、执行命令和访问本机 HTTP 的 Agent。可直接使用下面的指令，替换目录并补充自己的任务：

> 项目在【解压目录】。请先读根 AGENTS.md 和 START_HERE.md；存在 PACKAGE-MANIFEST.json 时先按 docs/PORTABLE.md 初始化、诊断和启动。Key 由我在 API 设置填写，账号由我扫码。读取当前账号预设，检查本次需要的云能力，再按我的素材与制作要求执行。付费和发布沿用我已明确给出的预算、账号与授权，保存原任务编号并交付结果。

夜间或每日执行由 Agent 宿主提供定时唤醒，执行机器和项目服务在约定时间保持可用。项目保存批次、队列与发布记录，Agent 继续检查结果并生成报告；只保存每日方案或退出一次 CLI 不会自动完成整晚流程。详细接入和恢复方法见包内根 `START_HERE.md`。

## 5. 连接正常之后还要确认什么

“连接正常”证明账户查询成功。具体制作还取决于当前账户已开通模型、云端已部署接口和可用额度：完整录音仍需 `haike/avatar` 与字幕识别能力；样音路线另需云端音色、上传、克隆和配音。配音中心能否读到可用音色，要以本账户实际查询结果为准。

云端音色/克隆、人物图精修等在源码中已有接口；交付包和本机历史成功记录不等于这些接口已对所有新账户部署、开通或验收。缺少接口、音色或模型时，Agent 应报告具体阻塞，由服务方完成部署或开通。已有本机私人配置和备用服务不随包分发。

联网素材/AI 分镜当前读取 `Haike_video/.backlot/studio-ai/relay.json` 中独立的 OpenAI 兼容 `/v1` 中转地址和 Key，尚未统一使用设置页的海客 Key。需要此能力时，由 Agent/服务方按 `Haike_video/scripts/configure_studio_ai.py --help` 将用户自己的私有 JSON 配置交给 `--file` 导入；采集 Chrome 路径按 `copy_skill/copy_skill-main/config/content_intelligence.local.json` 配置。这些私有文件不随包提供。仅填写海客 Key 并完成三平台扫码，还不足以使用这条联网分镜路线。

实际制作费用以执行前报价、调用结果和账单为准；本地图文合成免费。第一次付费制作或真实发布，应使用用户已授权的输入、预算与目标账号，完成一条完整任务后再安排连续批次。便携包的安装诊断不发起付费制作或真实发布。
