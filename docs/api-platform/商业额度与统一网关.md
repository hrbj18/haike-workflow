# 海客科技：账户、兑换码与统一模型网关

本地页面：http://127.0.0.1:17894/ 。本轮已实现账户中心和真实供应商适配器，尚未连接在线支付渠道；保留管理员账户与原数据库。

## 操作流程

- 用户可自行注册；管理员也可在「用户与充值」创建客户，填写显示名称、邮箱、初始密码。
- 管理员选择用户，填写金额和入账凭证，确认增加服务额度；后台记录管理员、用户、金额、时间与不可变流水。
- 「兑换码管理」设置每码额度、数量、有效期、可选绑定用户。明文只展示一次；发给用户由用户在余额页先查看额度、再确认领取。
- 用户创建一个平台 API Key，设置每日预算与有效期；所有已开通模型共用该账户余额。
- 用户或项目先免费报价，再明确确认费用上限；执行完成后查看用量、价格版本、冻结、实扣、结果及 CSV 明细。
- 管理员在「供应商与售价」管理密钥和版本化定价，在「运营账单」查看成功任务收入、估算成本、估算毛利和未知提交。

## API 与项目接入

地址为 http://127.0.0.1:17894/v2 ，请求头 Authorization: Bearer 平台Key。

| 能力别名 | 输入 |
| --- | --- |
| haike/text | messages、max_output_tokens；视觉内容用已上传图片的 image_file/file_id |
| haike/cosyvoice | text |
| haike/tencent-tts | text，单次最多150字符 |
| haike/tencent-asr | audio_file |
| haike/avatar | audio_file、image_file；服务端从 WAV 采样数计算25FPS总帧数 |
| haike/assets | query、media（videos/photos）、per_page |

先 GET /capabilities 检查开通状态，再 POST /quotes，确认后 POST /jobs；提交需要持久 call_intent_id 和 Idempotency-Key。GET /jobs/{id} 取状态与结果，GET /account/usage 查当前 Key 明细。POST /files?kind=audio/image 上传当前账户文件；支持5MB以内单声道PCM16 WAV、PNG/JPEG。

可复制的标准库客户端为 api-platform/gateway_client.py（同时需要 client.py）。项目内命令入口见 Haike_video/scripts/haike_api.py。客户端在调用前保存报价与意图，中断后 resume 原编号，避免重复扣费。仅需要海客平台地址与 Key，客户机不持有供应商密钥。

## 凭据与账本

供应商密钥已从用户指定文本导入忽略的私有目录；Fernet 加密文件与本地主密钥均限当前用户读取。后台接口仅返回是否配置和非敏感配置，不能读回密钥。后台更新空密码字段保留原值。备份时数据库和主密钥都需要私有保存；不得随技能包发给客户。

兑换码仅保存哈希。并发领取、管理员充值、预算冻结和结算使用同一事务边界；收支分录必须平衡。真实调用只使用管理员入账或兑换额度，既有模拟额度无法支付真实模型。配置真实供应商后禁用模拟到账。

供应商明确拒绝：释放冻结；同步调用中断或用量缺失：保留冻结、禁止自动重提；异步任务编号已落账：只查询原任务。未知提交由管理员提供实际用量和核对凭证后处理。超出原报价的供应商费用由商户承担，不追加扣用户额度。
