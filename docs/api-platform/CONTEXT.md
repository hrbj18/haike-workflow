# 海客 API 服务业务词汇

本词汇描述客户使用模型服务、充值及费用核对的业务边界。

## 账户与凭据

**客户账户**：拥有服务余额、调用记录和私有音色的客户身份。一个账户可以有多个用途不同的调用密钥。
_避免_：供应商账号、本地安装。

**调用密钥**：客户授予工作台或 Agent 调用模型服务及读取受限用量信息的凭据。
_避免_：供应商主 Key、管理员密码、网页登录凭据。

## 钱包与支付

**充值订单**：客户向平台购买服务额度的一次付款，只有确认到账才增加实付余额。
_避免_：模型调用订单、充值即收入。

**实付余额**：充值实际支付形成、尚未消耗的服务额度。
_避免_：赠送额度。

**冻结额度**：为进行中调用预留的余额，仍属于客户，尚未构成消费。
_避免_：已扣款、额外消费。

**可用余额**：尚未被冻结、可用于创建新调用的余额。
_避免_：钱包总额。

**赠送额度**：平台赠予客户购买服务的额度，按独立规则消耗，不等同于可原路退款的实付款。

**现金退款**：把符合退款规则的实付充值金额退回原支付渠道。
_避免_：任务退额。

## 调用与计费

**报价**：平台针对确定模型、输入及服务档位给出的价格规则、预计费用与费用上限。

**计费任务**：具有独立报价、交付标准和结算结果的一次模型服务。一个视频制作任务可以包含多个计费任务。
_避免_：本地生产队列任务、上游单次请求。

**实际结算**：根据已约定的计量和交付规则，将冻结额度中应付部分转为客户消费的过程。
_避免_：预占、目录价估算。

**任务退额**：返还某个计费任务已扣的服务额度；未扣款时释放冻结，不产生现金退款。
_避免_：支付退款。

**客户售价**：客户按平台公开规则购买服务的单价，使用任务确认时的价格版本。

**上游成本**：平台采购供应商服务实际承担的费用，可能与目录估算、客户售价不同。
_避免_：客户账单金额。

**加价系数**：客户基础售价与定价成本基准的比值。例如系数 1.3 表示基准上加价 30%。
_避免_：毛利率 30%。

**完整交付**：满足某计费任务约定结果的可用产物。例如双主持数字人任务要求两个角色的产物均满足约定。

**提交结果未知**：供应商可能已经受理任务，但平台没有足够证据确定结果，不能据此认定失败或再次创建。
