# 海客1.2.2更新工具兼容修订

修复原因：原工具只识别原1027和两个精确1.2构建，合法海客副本的提交标识`594980e14d722e5c98ac4296a1a5279080f7f8d1`也被拒绝。新工具依据海客项目身份、Windows x64平台、数据格式1和实际依赖判断，不以提交号作为升级资格。

原兼容补丁规则不变；本修订通过发行清单显式声明`project_compatibility`启用独立事务更新。公共代码与前端全量覆盖有备份，受保护配置/账号/素材/项目/作品不覆盖。原已导入个人.motion及其登记保留。已有1.2.2且完整的副本直接完成能力核验，缺组件时可进入修复。

依赖探测只运行本地版本/导入检查。缺失Python、Node、MSVC、FFmpeg或浏览器先下载固定SHA的归档并暂存；缺制作Python库使用固定版本依赖清单，经国内PyPI镜像在独立虚拟环境准备，不修改用户现有环境。依赖完整时不运行pip/npm，不额外下载安装基础运行环境。模板执行依赖和完整Remotion组件来自官方资源包，原复用来源缺失时有校验后的归档内容兜底。正式切换前再次验证字节，全部变更进入原程序事务和失败回退。

Python优先华为云，Node及浏览器优先npmmirror，Python库优先阿里云/清华/华为云，FFmpeg优先国内加速的固定上游归档，失败可回退上游同SHA文件。镜像返回HTML、下载损坏或依赖安装失败均停止，原服务尚未关闭。检查不假装下载成功，也不会安装本地Qwen或大模型。

compat3将“云端结果仍待核对”和“本机仍在执行”分开：制作记录为ambiguous且worker、租约均为NULL时，队列不会自动领取或重试，可保留原状态升级。升级备份额外保存本地队列快照和逐记录摘要，启动后核验记录未变；不修改原任务、凭据、费用或原作品，不为更新重发云端请求。真正执行、排队、暂停、等待人工或仍持有执行权的任务继续拦截；未知schema不能确认已释放执行权时也不放行。

compat4修复独立的本地音色门禁：完整的submission_unknown意图且生产端同一OS锁已释放，属于已停止的历史操作。事务备份preserved-audio-operations/包含原操作、供应商检查点、已生成片段及逐文件摘要，启动后核对未变；网页准备度、联网入口、离线事务与通用补丁共用判断。submitting/processing、持锁、缺日志/锁、损坏记录仍阻止更新。中转数据库意图缺少本地执行锁，不靠失败的GET推断已停止，原同账号查询规则继续保留。升级不触发本地音色恢复、不写终态、不重新计费。

使用当前haike-update.json的entrypoint重新下载compat4脚本；旧compat3仍会拦截本地历史音色。产品与两款模板保持1.2.2，模板资源复用原公开附件，不需重复发行。源码checkout、其他产品、平台/数据格式不兼容、越界/链接路径仍拒绝。另一台物理机的验收与本机隔离证明分开记录。
