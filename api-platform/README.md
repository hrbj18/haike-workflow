云端账户中心：https://8.138.207.71:17894/ ，统一网关使用 `/v2`；本地开发默认回环17894。账户、商业额度、兑换码、版本化定价及供应商网关通过管理员入账和兑换码充值，尚未接入微信/支付宝在线支付。源码统一由根私有Git仓库管理，分支、检查及迭代见 [Git管理](../docs/GIT_WORKFLOW.md)，不要在本目录嵌套初始化另一个仓库。

## 启动

Mac 双击根目录的「启动API账户中心-Mac.command」；Windows 双击「启动API账户中心-Windows.cmd」。或在本目录运行：

```sh
uv sync --frozen
uv run --frozen python launch.py
```

首次运行用用户名和密码创建管理员；用户注册也只需这两项。用户名去除首尾空白、忽略大小写，不限制中文或字符组合；密码只需非空，不设长度下限或复杂度要求。已有邮箱账户可继续用原邮箱作为用户名登录，余额、Key 和账单保留。服务只监听回环地址，当前不能直接作为公网商用站点。接口说明位于 /docs，完整 OpenAPI 位于 /openapi.json。

## 统一 Key 的项目 / Agent 接入

用户电脑只配置平台地址和Key，不需要供应商密钥。源项目内命令如下：

```sh
cd ../Haike_video
python scripts/haike_api.py configure
python scripts/haike_api.py models
python scripts/haike_api.py summary
python scripts/haike_api.py upload --kind audio --file 配音.wav
python scripts/haike_api.py call --model haike/cosyvoice --input-json 参数.json --max-yuan 1
# 核对后明确确认，才会接受付费任务：
python scripts/haike_api.py call --model haike/cosyvoice --input-json 参数.json --max-yuan 1 --confirm
python scripts/haike_api.py resume call_原调用编号 --wait
```

配音参数JSON为 {"text":"你好海客"}。客户端在提交前保存原报价、意图和幂等键；响应丢失时恢复同一编号，不重建任务。Python SDK为 gateway_client.HaikeClient（标准库，需同时带client.py）。两者同样支持环境变量 HAIKE_API_BASE_URL、HAIKE_API_KEY；平台Key不要放到命令行、URL或共享项目文件。

原生产队列的第三方供应商入口没有自动整体替换，迁移通过统一客户端进行，仍需保留预算、任务来源及生产审批。

## 资金与恢复约束

账本使用整数微元（1元=1,000,000微元），成本与价格计算使用Decimal，总额向上舍入一次。收入、费用上限和余额均用整数字符串传输。充值、兑换、冻结、预算和结算使用SQLite串行事务；原始资金凭证禁止更新/删除，所有分录必须平衡。

商业额度仅来自管理员入账与兑换码。既有模拟额度只能用于演示任务；真实供应商配置完成后，模拟付款确认被禁用。兑换码哈希存储、原子领取，同一账户重复确认不重复到账，其他用户不能再次领取。

供应商明确拒绝时释放冻结；未知提交或缺失用量时保留冻结，禁止自动重提。已保存异步任务编号则只查询原任务。超出已确认报价的采购费用由商户承担。新价格只影响新报价，已确认任务沿用原版本。

源码新增POST `/v2/quotes/{id}/renew`（`{"confirmed":true}`）：报价初始10分钟有效，登录或来源审核暂停后可延长同一报价的接受时间；保留原价格、供应商、输入快照与唯一报价编号，最长从首次报价起24小时。已受理报价返回原编号，仅恢复原意图；关闭模型或超过24小时要求重新确认，不能克隆成第二个付费任务。此接口尚未发布到现有云端版本。

供应商密钥位于忽略的data/providers.encrypted，本地主密钥data/providers.master.key为私有文件。供应商页面无法读取明文。导入工具为 import_providers.py --file 私有清单路径，仅输出配置状态。数据库、主密钥、供应商文件和客户媒体不得发给客户；生产备份需同时保留数据库与主密钥。

## 统一中转与用户端简化（2026-10-13）

用户导航保留「余额与充值、API Key、调用账单、账户与安全」四个入口；模型目录、接入试用与运营功能由管理员使用。用户申请平台 Key 后，只配置 `/v2` 地址和 Key，调用参数指定平台模型编号；所有已开通模型共享商业余额和该 Key 的每日预算。新模型开通无需重新签发 Key。模型 API 只返回已开通能力，不包含供应商、上游型号或密钥配置状态；账单保留实际调用的模型编号用于核对。

管理员在「供应商与售价」添加 OpenAI 兼容平台（渠道编号 `channel/xxx`），再接入模型（编号 `haike/xxx`，填写上游平台、上游模型 ID），输入采购成本并发布价格，开启渠道及模型即可使用。新增平台目前支持文本/视觉的非流式 Chat Completions 协议，配音、识别、素材、数字人沿用内置专用适配器。新的真实价格固定为采购成本 × 1.5、附加服务费零；旧报价与历史账单保持原快照，不追溯修改。

调用报价保存模型身份、计量方式、渠道地址及上游模型快照；管理员改路由或价格不会改变已提交任务。密钥从服务端私有保险库读取，用户端不会接收上游密钥。未知提交保留冻结、禁止自动重提；确定失败释放，采购费用超出已确认上限由商户承担。

账单详情含逐项用量、每份售价、计费金额、系数、合计舍入差额、上限减免、释放额度和本次资金凭证。每行展示向上舍入至微元的金额，合计只舍入一次，因此差额单列；不能将逐行舍入金额直接相加当作实扣。CSV 支持当前模型/状态筛选，运营后台另有客户、估算采购成本与毛利导出，余额页支持资金流水导出。各导出当前最多 500 条，均做账户权限检查与电子表格公式转义。商业冻结及本月消费独立展示，不混入演示消费；月消费按结算时间的上海月份计算。

模型卡片的「前往接入」现在直接打开该模型对应平台的 API 地址与密钥表单，显示当前采购单价、调用售价和系数；高级音色/模型/工作流设置折叠显示。腾讯云使用 SecretId / SecretKey。密钥留空保留已保存值，保存后留在模型列表；未发布采购价的档位显示「价格待确认」，可直接打开对应定价表单。这个入口仍仅供管理员配置上游，普通用户继续使用统一平台 Key。


## 私域充值与用户管理（2026-10-13）

用户在私域渠道付款，提供用户名；管理员核实收款后，在「用户与充值」手动入账，或在「兑换码管理」为付款用户签发绑定码，再通过原私域渠道交付。手动充值立即到账；发码仅登记收款，用户预览并确认兑换后才到账。充值 ¥100 增加余额 ¥100，1.5 倍只应用于模型调用，充值不再乘系数，也不算调用消费/收入。

手动充值页面只需选择用户和填写金额，核对后确认充值；后台自动记录金额、用户、时间、操作人及默认备注“管理员手动充值”，不要求填写收款渠道、交易单号或备注。兑换码页面仍填写收款渠道、唯一凭证/交易单号、备注，并确认收款；旧客户端手动充值也可继续提供这些字段，已填写的凭证在手动充值和发码之间共同去重。手动充值按幂等键重试；发码重复请求不签发新码，重试不回显先前明文。若明文丢失，可重新签发未使用、未作废、未过期的码：金额、绑定用户、有效期和收款记录保留，旧码原子作废；已兑换码不能替换。既有接口调用可继续仅提交旧 note/batch 字段，但没有凭证字段的历史请求不参与跨请求凭证去重。

「充值记录」分别展示收款登记和实际到账，保留来源、金额、用户、操作人、收款凭证、备注和兑换进度；用户只能读取本人已到账记录，不能读取私域收款单号和内部备注。列表/收款导出最多 500 条。用户端充值联系方式和说明由管理员在「用户与充值」底部配置，未配置时引导用户通过原私域渠道联系。

管理员开户或重置密码后，用户需修改临时密码才可使用充值及 API；自助改密验证当前密码并撤销其他会话，保留 API Key。管理员只能停启用或重置普通用户，不能通过客户操作停用管理员。停用撤销登录会话并阻止 Key 新调用，余额及历史账单保留，已接受任务继续结算；重新启用后原 Key 恢复，用户须重新登录。忘记密码由原私域渠道核实身份后管理员重置，没有匿名直接重置密码接口。

新增表采用 `CREATE TABLE IF NOT EXISTS`，不重写原账户或资金账本；已有用户默认为正常状态，不强制重设密码。此次自动测试 51 项通过，另验证管理员手动入账、绑定码签发、用户确认兑换及充值明细、账户手机布局。测试未涉及真实付款或收费调用。

登录、注册和管理员开户接受 `{ "username": "用户名", "password": "密码" }`。旧客户端的 `email` 和可选 `name` 字段继续兼容；响应新增 `username`，内部历史 `email` 字段仍保留用于旧接口。用户名重复返回 409 / `username_exists`。用户名最多 120 字符、密码最多 128 字符仅用于限制输入体积，界面不要求邮箱、显示名称或确认密码。
