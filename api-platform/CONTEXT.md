# 海客 API 账户中心领域

**服务额度**：管理员确认入账或用户领取兑换码后得到的可用额度，用于支付已开通的第三方模型。

**模拟额度**：演示付款生成的测试额度，只能用于演示任务，与服务额度隔离。

**兑换码**：携带固定额度、有效期与可选领取账户的一次性凭证。查看额度不会领取；首次确认领取到账；同账户重复确认返回原领取结果。

**平台 Key**：用户签发的模型调用凭据。同一个 Key 可调用所有已开通能力，共享账户余额，另受 Key 的每日预算约束。不能用于充值或后台管理。

**采购成本**：供应商收取的费用。公开标价只用于估算，实际费用以该账户的采购账单为准。

**客户售价**：用户支付的服务价格。默认采购成本乘 1.5；后台可调系数与每次服务费。

**毛利**：客户实扣减采购成本。成本尚未对账时只称估算毛利；不等同于净利润。

**报价**：固定本次模型、输入、用量上限、价格版本、费用上限的限时记录。报价不发起供应商调用。

**调用意图**：客户确认一次调用时生成的持久编号。网络中断后沿用该编号恢复，不新建付费任务。

**冻结**：接受报价时占用额度和每日预算，尚未计为消费。

**结算**：确认成功及用量后扣费，释放剩余冻结。客户实扣不得超过已确认费用上限。

**未知提交**：不能确定供应商是否接受、完成或返回完整用量。保留冻结，禁止重复付费提交，等待凭证核对。

**价格版本**：已发布的成本与售价规则。新规则只影响新报价，旧报价和已确认任务保留原版本。
