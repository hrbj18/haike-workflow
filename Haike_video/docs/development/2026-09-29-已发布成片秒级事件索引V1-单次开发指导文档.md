## 1. 本次目标与产品边界

用户已有一批由同事剪好、且已经发布的视频。本次只解决本地资产查找：搜索所有成片讲了什么，以及唱歌、跳舞、比心、大笑、鼓掌等可用于重新剪辑的互动出现在哪个时间区间。搜索结果能直接播放对应原片区间，人工能修正自动候选。索引需为未来解说版、主题合集和短版剪辑提供稳定来源，但本次不生产、不发布新视频。

本次交付同时支持两层检索：视频级标题和摘要；片段级有起止秒数的转写、事件与标签。视频文件只读，索引文件不进入 Git。视频没有可靠语义证据时显示“未确认”，不把文件名、音量、运动强度或模型猜测伪装成人工确认的歌舞事实。

用户可见的成功路径：打开“已发布成片索引”→搜索“唱歌/跳舞/比心”等词→看到跨作品命中的视频和起止时间、来源、证据与审核状态→点击即从该时间播放→修正标签和起止点→再次检索得到修正结果。

## 2. 已有基础与差距

- `backlot/media_index.py` 有视频内容指纹、媒体探测、镜头起止时间以及单素材画面/转写检索；`material_overview.py` 能做快速概览。两者尚不是跨成片的全库事件索引。
- `material_interactions.py` 有互动事件起止时间、亮点帧与证据；`material_interaction_recommend.py` 有情绪/歌舞推荐分，但混合了词语和模型互动度，不能直接作为“确实在唱/跳”的标签。
- `material_audio_envelope.py` 和 `material_motion_timeline.py` 可提供声音和运动证据；声音大或运动强不直接证明情绪/舞蹈。
- 本机有 FFmpeg、OpenCV、faster-whisper 和已缓存的本地 small 模型；本次不调用云端 ASR、视觉模型或付费服务。视觉内容的自动精确动作识别不在现有模型能力之内，依靠证据候选和可操作的审核界面闭环。
- 目标目录 `D:\刘宇钊\粤仔视频\原素材` 当前有 69 个文件。该路径是本次数据输入，运行时必须可配置，不能硬编码到产品代码。
- 当前工作树含大量其他任务的未提交改动。只编辑本任务新文件和经过核对的极小集成点，不重置、不覆盖其他功能。

## 3. 数据与行为合同

1. 使用本地 SQLite 保存视频、别名/路径、转写段、事件及事件标签。视频内容指纹沿用 `media_content_fingerprint`，改名后识别为同一内容；发现同路径内容变化时保留旧版本与人工标签，不静默套用旧标签。
2. 每条事件有 `video_id`、`start_seconds`、`end_seconds`、`peak_seconds`（可空）、`summary`、`tags`、`source_kind`、`confidence`、`review_status` 与可追溯的证据。事件可重叠；区间必须在原片时长内且 `start < end`。
3. 转写段与事件分开保存。转写由本地模型产生，记录模型身份；字幕或文件名只作为文字线索。关键词“唱/跳”最多产生待审核候选，不直接标为确认歌舞。
4. 索引分为 `registered`、`transcribed`、`candidates_ready`、`needs_review`、`reviewed` 或 `failed`；每个文件单独记录错误和重试条件。导入可重复执行且不复制原视频；重试不得覆盖人工修改。
5. 检索同时覆盖文件名、转写、事件摘要和标签；文字结果说明命中来源。标签筛选使用受控词表和同义词，支持只看人工确认结果。默认搜索可返回候选，但必须醒目标注状态。
6. 每条搜索结果返回片段前后可播放范围。媒体接口只允许读取当前索引中登记且仍处于受信任输入目录内的本地文件；禁止以 URL 参数直接读取任意磁盘路径。
7. 本次仅建立本机成片索引，不将它等同于项目制作资产库，不修改已有的二次精剪、发布和统一生产队列合同。

## 4. 具体任务与顺序

### T1：基础登记和稳定身份

建立独立模块与 SQLite schema，扫描指定目录的视频文件；探测时长、分辨率、声音流、文件大小，计算内容指纹。已登记文件重跑应命中缓存；改名保留人工标记；内容变化另建版本。对损坏文件记录失败，其余文件继续。

### T2：本地转写与秒级文字检索

封装本地 faster-whisper 模型及 FFmpeg 音轨输入；每条成片写入有起止时间的转写段。缓存与模型版本绑定，失败可按单条重试。转写仅作为检索线索；保留语言和不确定性，不用字幕推断真正原声。

### T3：事件候选与既有能力接入

从转写中找话题和显式情绪词，从已有可用的互动索引导入事件时间和证据；有视觉索引时利用镜头摘要。将“提到唱歌”“实际唱歌”“背景音乐”“不确定”作为不同类型。全片保留时间覆盖，候选只负责提示审核；音量和运动证据仅用于排序与定位。允许人工建立音频/视觉自动规则漏掉的事件。

### T4：跨视频搜索与审核

实现可筛选的跨视频搜索、区间播放器、事件新增/修正/确认/驳回。每次人工修改后立即更新结果，并显示来源与修改状态。列表可区分已转写、待审核、已审核和失败。

### T5：命令入口与工作台接线

提供目录扫描、索引推进、状态查看 CLI；在现有 FastAPI 工作台增加独立页面及小范围 API/媒体接口。扫描和长时转写由 CLI 或受控后台任务触发，网页请求本身不阻塞数分钟，也不重复启动分析。

### T6：真实样本验证与交接

先用此前看过的两条视频做端到端样本，再跑目标目录的元数据登记与可负担的本地转写。对真实样本核对可见字幕/原声及精确区间；记录人工确认数、待审核数、失败数。更新最小的 handoff 文件并执行上下文审计。

## 5. 开发前准备和实施原则

1. 核对 `git status`、相关文件差异、现有接口和 UI 布局，保存其他任务的未提交改动。
2. 确认输入目录文件数、FFmpeg 对、模型缓存、GPU/CPU 可用性及本地输出目录。不能在索引阶段触发模型下载或云端费用。
3. 先实现小而可验证的 SQLite 契约与单条导入；再做转写与事件候选；最后接 API/UI。每一步用隔离测试数据库验证后再触及真实目录。
4. 所有自动标签附来源和审核状态。无法在不听音频/看连续动作的情况下证实的事件，必须保留待审核。
5. 媒体处理和索引写入可中断、可恢复；不移动、不覆盖已发布原片；人工修改优先于自动刷新。

## 6. 验收标准

### A. 数据安全与幂等

- 测试库中重复扫描同一文件，视频数和人工事件数不增加；文件改名后内容身份与人工事件不变；同路径换成不同内容后不继承旧确认标签。
- 坏视频导致单项 `failed`，不阻断其他文件；原视频字节和修改时间不变；数据库留在忽略目录。
- API 不接受任意路径读取；不在日志或页面泄露密钥。

### B. 秒级索引与检索

- 两个真实样本能入库，转写段和人工事件均携带实际起止秒数；搜索“比心”等词返回正确视频和区间；点击结果从相应时间播放。
- 多事件可在同一区间重叠；边界越界、负时间、零时长均拒绝；修正后查询立即反映修改。
- 搜索能区分文件名命中、转写命中、候选标签命中和人工确认标签命中；“唱歌”台词不能自动变成已确认的唱歌事件。
- 标签筛选可跨所有已登记视频，能只看已确认结果；未转写/失败的作品仍能按名称找到，状态清晰。

### C. 真实目录与质量

- 目标目录全部可读视频完成登记或给出逐项失败原因；输出总数、可检索数、已转写数、候选数、人工确认数和失败数。
- 至少核对两条真实作品的搜索结果与画面/音频证据；样本中的事件时间误差以人工回听/播放为准，不以毫秒字段精度冒充识别准确率。
- 对一组包含“真正唱歌/跳舞”与“仅背景音乐/提到歌舞”的样本进行人工复核；若目标目录没有足够已证实样本，则如实记录覆盖不足，自动标签保持候选。

### D. 工程质量

- 模块/CLI/API 的重点测试通过，包括去重、版本变化、搜索排序、权限边界、人工覆盖、失败恢复。
- 完成现有相关回归测试与 `python scripts/audit_context_handoff.py`；若出现既有失败，附具体证据且不将其冒充本次通过。
- 页面在真实本地数据上可打开、能搜索、能播放与修改事件；生成的索引状态可在页面/API/CLI 读回。

## 8. 本机使用与交接

在 `Haike_video` 仓库中使用 PowerShell：

```powershell
& .\.venv\Scripts\python.exe scripts/published_clip_index_cli.py scan --source 'D:\刘宇钊\粤仔视频\原素材'
& .\.venv\Scripts\python.exe scripts/published_clip_index_cli.py transcribe
& .\.venv\Scripts\python.exe scripts/published_clip_index_cli.py status
& .\.venv\Scripts\python.exe scripts/published_clip_index_cli.py search '唱歌'
```

`scan` 可重复执行且不会复制原片；`transcribe` 跳过同模型已完成的文件。已有视觉概览可用 `import-visual-overview <analysis.json>` 接入，互动索引可用 `import-interactions <index.json>` 接入；两者都要求来源指纹匹配，并只生成待审核候选。启动或重启工作台后打开 `/published-clips`，点击搜索结果核对画面与原声，填写核对依据后才能确认事件。旧工作台进程不会自动加载新路由；不要因页面暂时 404 误以为索引数据丢失。
