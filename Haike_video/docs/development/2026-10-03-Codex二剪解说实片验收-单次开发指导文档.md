# Codex 二剪解说实片验收 · 单次开发指导文档

日期：2026-10-03。用户已选择使用粤仔素材做主题二剪。

## 本轮目标与范围

先由当前 Codex 完成一条可观看、可复查的真实成片，再决定能力模板化。本轮不启动《轻量二剪解说V2》功能开发，不以 ds4.1 的生产测试作为前置条件。

主题暂定「粤仔如何把路人聊成朋友」。使用现有美国游客及法国游客两条公司内部精剪素材，新的短句解说串联现场原声、比心与游客反应，最后落到笑容或合影。目标30—60秒、9:16，无数字人。人物真实互动是本片主体，因此不套用科技模板的无人脸要求。

新解说不重复原片全套口播，不夸大机器自主能力、人物国籍或事件因果。已有转写是定位线索，画面和原声需要实际核对。原片烧录字幕可在保留现场原声时作为原有现场翻译保留；新增解说优先用无字幕的短窗，不能把原有不对应的台词当新解说字幕。旧片头/片尾不使用。

## 前期准备与生产路径

1. 核对两条成片身份、文件哈希、转写、全片多宫格；对真实采用窗口补密集帧。保留未知，不把抽帧当连续播放/回听。
2. 建独立项目 `yuezai-friends-codex-pilot-20261003`，当前agent负责主题、文案与看图；复用 OpenMontage 工作台清单、字幕、队列和渲染。另一个聊天的机器人任务不参与本轮修改。
3. 只给数句短解说，先用当前配音中心默认腾讯·智兰（音色501001，沿冻结语速）生成并量实际时长；限制3句、总文本≤120字，既有结果复用，不自动重发受理不明任务。没有数字人/图像/视频生成调用。文本/视觉不调用其他模型。
4. 依据音频时长确定源窗；解说窗源音轨静音，现场窗保留原声。使用本地轻音乐时，人声下压低且不重复叠加原片已混入的BGM。按源轨情况决定是否加音乐，并记录实际选择。
5. 本轮可以在项目内准备一份有来源区间和文本记录的音频母版（新解说+现场原声+有限淡入淡出）；由既有 `source_audio_only` 工作台合同消费这个项目音轨。该模式只表示渲染音频来自已登记母版，不表示母版内容完全是旧片原声。项目清单明确记录母版如何制作，不能把它当作尚未实现的通用V2能力。
6. 逐段画面绑定项目资产与原片区间；时间轴由实际声音驱动，无拉伸、循环和长定格。画面不要强行裁掉狗或游客。定时字幕与画面时钟一致；现场原片已有字幕时避免新增重复台词。预览通过统一 `full_preview` 队列提交，不直接调用生产runner。
7. 两次独立检查以内：一次结构/来源/字幕时序检查，一次成片代表帧/音轨/技术检查。只局部修复失败段，旧版本保留。输出到项目库，交付待人工观看，不发布。

## 任务

- T1：本指导文档、原片证据及基线。
- T2：确认主题和剪辑结构，写原创短解说、生成实际配音并冻结。
- T3：确定镜头与现场原声窗口，准备并登记音频母版、原片和源区间清单。
- T4：工作台字幕/画面编排，通过统一队列生成待审片。
- T5：检查、局部修复、项目库读回，交付成片与本轮制作复盘。

## 验收标准

1. 30—60秒真实成片，至少两份原片，至少两段新解说和一段可辨认的现场互动；有明确开场、互动发展和结尾。新解说与所见画面相符，保留互动上下文。
2. 每镜有原片ID/路径、哈希、源入出点、原声方式；新配音保存文本、音色、语速、调用或复用记录及实际时长。原素材、旧成品和另一个聊天的项目不变。
3. 输出1080×1920或720×1280、固定30FPS、H264/AAC；全片解码通过，画面/音轨时长误差≤0.08秒。响度目标沿当前项目策略，误差≤1.5 LUFS，TP≤−1dBTP。
4. 新字幕清晰、不越界、不遮挡主要人物和动作，不叠错旧字幕；源字幕、贴纸的保留范围明确记录。短窗和切口有实际读图证据；无原片推广尾卡。
5. 解说窗没有默认叠加原博主口播，现场窗语句不被机械切断；能够播放/下载同一版本，完整音轨交付可回听。如果当前工具不能听音频，报告必须标记听辨待人工，不能编造已听验。
6. 统一队列状态及项目库读回可追溯，失败不暴露半成品、不覆盖旧版；只交付待审片，不授权本聊天发布。
7. 最后复盘哪些步骤已有接口可复用、哪些需要手工处理，以及是否真的需要V2新模块。未实现能力和未测试模型明确保留待办，不以一次成片成功证明全自动/平台风险/低成本模型能力。

### 本轮问题与处理

- 旧转写的时间点不足以确定干净画面，密集帧发现字幕、贴纸和推广卡；重新选用真实无字幕短窗，不做损伤构图的强裁切。
- 最初39秒草案切口上下文偏紧；在结构检查中扩展为41.7秒，保留旧草案与母版。只有一个实际视频预览版本，未重复付费。
- `source_audio_only`的遗留review_note默认称“复用原文案”，与本片不符；只修正此项目的内容标记为“原创解说＋现场原声混合母版”，没有改通用实现。前端仍泛称“原音轨”，作为后续产品文案提案。
- 默认配音中心返回公开profile，运行时另取具体profile后冻结；最初本地断言在调用前停止，没有重复提交供应商。music tracks返回结构也已按实际接口处理。这些不是供应商故障或已验证的通用代码缺陷。
- 供应商已受理3次TTS，共53字符；适配器返回费用估计0，不能据此宣称免费，实际扣费以供应商账单为准。本地ASR和FFmpeg无新增云端任务。

### 后续工程判断

现有资产登记、source_audio_only消费项目音轨、定时字幕、完整画面绑定、统一队列、预览/下载与响度处理已能支撑这次Codex实片。本轮成功的是“agent手工导演＋项目内音频母版＋既有渲染”，并未实现通用自动二剪解说功能。

人工审片认可后，优先考虑把**每段新配音/现场原声的音频合同、源窗和字幕绑定、片段级重做/复用、混合母版的真实内容标识**接成正式工程入口。语义选材仍需实片证据与独立真值，不能先扩大无人审核自动选材。ds4.1、跨素材全自动效果、平台发布风险和批量成本均未验收；原V2开发方案继续暂缓。
