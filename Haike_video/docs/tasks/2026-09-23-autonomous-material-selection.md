# 自动素材选择 V1：任务合同

## 目标

用户只确认主题和观看最终待审片。素材选择按项目场景时间轴进行，兼容 9 秒模板和较长的数字人口播；任何片段时长由场景、镜头和模型建议共同决定，不设 3 秒常量。

## 输入与职责

1. 素材获取层交付具有稳定 ID、来源、授权状态、实际时长和本地文件的素材池。CopySkill 常规 `00-素材目录.json` 和 `download_only` 原片 `清单.json` 均可导入；指定抖音时只接受能核验为抖音的素材，不静默换源。
2. 现有多宫格概览负责发现候选区间；镜头级视觉理解 V2 负责验证连续区间、可见文字与画质。仅概览证据不能直接进入时间线。
3. 任务冻结本次 agent 选定的模型名；多宫格、镜头级视觉理解与语义选镜使用同一模型。模型只能引用已验证的 capability ID；程序负责时间、来源、画质、重复、锁定与覆盖检查。
4. 输出 `material_selection_plan`：每个场景的源素材 ID、源入出点、显示入出点、模型身份、视觉索引指纹、拒绝理由和覆盖状态。
5. 只有所有目标场景完整覆盖且校验通过，才能一次性写入工作台视觉时间线。预览和最终片继续使用同一条时间线；不自动批准或发布。

## 失败和恢复

- 视觉证据只有概览、来源不符合指定平台、源画面有文字/水印/明显模糊、时长不足、模型捏造 ID 或时间、锁定画面、脚本或索引变化：明确失败并保留原因，不保存部分替换。
- 补采素材或重新分析后可重新运行；同一输入的模型选择结果须带模型和输入指纹，便于诊断。
- 制片 agent 可以据 `needs_more_material` 自动补采并最多重试两轮，之后输出诊断；本轮实现选择与采用的可靠合同，补采由现有素材获取流程承担。

## 验收

1. 9 秒与较长场景都能根据实际时长生成无缝、多镜头计划；没有固定 3 秒限制、循环或变速。
2. 指定 Douyin 时混入 Pexels/无来源素材会被拒绝；源画面文字和高模糊镜头会被拒绝。
3. 仅多宫格概览不会被误当成连续镜头；镜头级索引与来源发生变化时禁止采用。
4. 全片选材一次提交；任一场景不足、锁定或版本冲突，工作台无部分写入。
5. 产物保留稳定 ID、源时码、索引指纹、模型身份与每场景覆盖记录；现有审核预览仍需重新渲染。

## 当前实现边界（09-23）

- 已实现标准目录导入、多宫格与 V2 的交集选段、选定模型覆盖、整片队列选材和原子采用；合成仍沿用原时间线。`POST /api/production-queue/jobs` 的 `kind=material_selection`，`request` 包含 `required_platform` 与 `model`。
- Cookie 抖音搜索/下载仍由 CopySkill 执行；素材不足时产出 `acquisition_requests` 给 agent 补采。概览、V2 索引和最终预览目前由 agent 顺序提交现有任务，尚无一个后台父任务将这些阶段自动串联。
- 验收已覆盖短片、24 秒多镜头场景、来源/画质/字幕门、时码越界、锁定/来源变更、模型不可用时不回退、真实 FFmpeg 合成、统一队列和 HTTP 提交。真实 V900 与两条数字人口播项目还缺本轮模型一致的概览 + V2 索引；两条长视频当前没有登记的视频素材。因此本轮测试证明链路合同和合成能力，不宣称这三期真实素材已自动生产完成。
- 真实模型连通性（2026-09-23）：当前项目中转站用 `gpt-6-sol` 执行三图顺序视觉测试及最小 JSON 文本测试，两个接口均返回 HTTP 404“接口或模型不存在”；用已配置的 `gpt-5.6-terra` 执行相同测试均通过。生产任务要求模型身份一致，不能把 Terra 索引静默用于 Sol 选择。上线前须让选定模型同时通过视觉与文本接口测试，重新生成相同模型的概览和 V2 索引，并在真实项目完成全片选材、预览合成和人工终片检查。
- 端到端无人值守仍有编排缺口：Cookie 搜索/下载、导入、两级视觉索引、素材不足补采、重新选材、预览合成尚需 agent 依次调用现有任务；当前的 `material_selection` 父任务只管理选材与原子采用。后续应增加一条可恢复的项目级任务，把各阶段的输入指纹、重试次数、产物和明确的停止原因记录在同一任务账本中。
- 同日需求修正：默认生产入口为 Codex 当前 agent；新增 `docs/tasks/2026-09-23-agent-native-model-routing.md` 作为模型执行方式的现行合同。此文件上方关于中转站 `gpt-6-sol` 404 的记录仅代表显式 `relay` 路径，不能再当作 agent 原生路径的阻塞。
