# 深色原生模板：受控内容替换短片

文档类型：implementation。原生动作来自已验签的 `template-03-native@2.7.18-alpha.2`，不修改保护实现。执行入口仍为 `scripts/dark_native.py` 和既有统一生产队列；本页描述原122.4秒对照合同的兼容扩展，不把新输入的测试通过当作成片验收。

## 保持与替换

人物窗口、深色几何、运动轨迹和整组状态由官方运行时保留。只在公开 `brief`、`candidates[].inputs`、`media.talk/captions` 及素材槽替换本期内容。人物口型来自同一完整口播，不循环短缓存；静态头像槽也换成同一授权形象。

原生公开画幅为横版/竖版；本入口当前正式输出限定1920×1080/60fps。4:5伴随版将完整横画面缩放到1440×810，置于1440×1800画布中央，无裁切，不能称原生4:5重排。

## 短片清单扩展

原manifest必需字段保持不变。受审核的短片可以显式增加：

```json
{
  "expected": {"width":1920,"height":1080,"fps":60,"frames":1836,"seconds":30.6},
  "audio_mode":"native_plus_music",
  "music":{"path":"<本期授权的本地配乐绝对路径>","gainDb":-5,"offsetSeconds":0,"loop":true},
  "portrait_companion":true
}
```

以上只是字段示例，不能直接提交。`expected`必须与实际官方计划、完整音轨和已实际查看的本期预览一致。计划技术回执还须提供同序`completeGroups`及逐组`completeGroupFrames`，总和等于全片帧数，每组达到公开最低帧数。S02和S03必须同时存在、相邻且维持同一主素材的连续源时钟；不能把十组塞入30秒或整体快放。当前控制范围为6–600秒、1–10个不重复完整组。

没有`expected`的新manifest继续适用原122.4秒、7344帧、十组的严格合同。历史完成请求沿原身份和已绑定输出恢复，不因扩展入口而补生成伴随版，也不重发已有付费任务。

## 声音与帧时钟

- `audio`绑定本期完整原声PCM；帧时钟不可短于它，最多追加2秒明确非语音尾白。字幕沿用同一源实际ASR边界，不能按字数匀分。
- 旧默认`original_mix`继续规范化既有完整混合轨一次，不叠加配乐或音效，适用于原版完整对照。
- `native_plus_music`先全解码官方raw音轨，把原生口播与动作音效作为一个完整声源，仅再加入一个显式绑定、冻结SHA的配乐。它不再添加`audio`中的口播，不再添加另一套SFX，避免重复。官方raw音轨须与受审全片时钟相符。
- 配乐路径、增益、入点、是否循环均冻结；不暗中生成新配乐或换供应商。短配乐需明确`loop=true`；口播与真实素材不循环。
- 最终母带为48kHz立体声，按60fps精确到每帧800采样；仅修正容器边界与已声明尾白，不伸缩口播。主片H264/yuv420p、实测至少20Mbps、AAC48k双声道、真峰值≤−1.5dBTP并全解码。

## 同队列伴随版与验收

`portrait_companion=true`在同一父队列任务中导出`dark-native-4x5.mp4`，音轨复制主片，完整帧数不变，20.5Mbps目标。主质量回执与result同时绑定伴随版SHA；作品库使用独立`portrait45`作品键。字段缺省时不生成该版。

先完成本期数字人/素材来源与费用闸门，运行官方check/plan/prepare/preview，实际看帧后才能冻结执行。完整输出需另验角色、文字、真实素材、整组动作、源时钟、原生SFX与BGM；数据探测或信号测量不能冒称连续人耳听审、音素口型、设备或用户验收。

本期布局预演若使用静态人物，必须明确标注preview-only，不能当作数字人口型结果。真正制作使用新绑定的完整同声源人物视频并重新计划、预览和冻结。
