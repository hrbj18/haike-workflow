# 参考复刻与原生模板接入

2026-11-01，本机开发验收范围。制作与发布分开；以下不表示任意.motion都能自动成为成熟模板。

## 三层保存

1. 原始证据：参考视频、个人.motion原包与版本SHA、实拍、完整声音、原始ASR记录。个人封套只保存在忽略目录。
2. 可复用模板：项目源码组件，或原包公开的参数/控件/制作协议。镜头动作、版式、槽位和容量与本期文案分开；受保护模板不复制核心源码。
3. 每期制作：草稿、绑定素材、完整台词与时码、冻结请求、计划、预览审核、队列任务及成片版本。换声音须重新编排，不靠拉伸、循环人物或末帧补齐。

蓝白模板不需要个人.motion。原包路线需要本机已有授权原包；接入器和本期参数不替代模板授权。点阵手账允许制作商业成片与修改，不允许再分发模板；不把个人包、字体或人物混入公共源码交付。

工作台“动效模板库”默认进入画廊。已导入原包自动出现在“已导入 .motion”分类；卡片区分待核验仅检查、仅参数编辑、开放制作接口，明确绑定样片后单独显示本机开发样片。卡片一键定位对应原包，草稿列表随当前包筛选。画廊读取登记元数据，不执行原包，也不把默认参数、个人封套、原包路径或密钥投影到卡片。未来同协议包无需再手写画廊卡片；新的执行协议仍需独立适配。入口规则见[原包画廊指南](../templates/motiongit-imported/README.md)。

官方helper采用独立HTTPS版本SHA固定，新增rc.54；已核验旧包保留原工具。之前未识别的包须显式重新核验，未知版本保持只读，不能仅改状态放行。依赖只按同一原包SHA、helper身份和安装清单复用；清单变化保留旧缓存，新建安装目录。计划/准备仍检查真实环境。

## 原生制作与恢复

HTTP前缀`/api/studio/motiongit`。`POST /drafts`保存完整参数，`POST /drafts/{id}/assets`以平面文件名上传绑定；`/check`检查结构，`/produce`冻结并提交统一队列。motion-kit首次preview返回计划：通过`/productions/{project}/{render}/plan-review`实际审核后再生成preview；全部实际图片通过`/review`后才能render。原生知识路线使用自己的句级证据与预览合同，通过同一制作记录和作品中心恢复。

文件名、尺寸、全片时长、实际窗口和同源SHA都有执行检查。局部事件帧是编排参数；只有真实ASR词证据才可称词级识别。句级证据可以驱动整句表达，不能均分汉字推造时码。精确原生版本缺开放能力时，应记录缺口并新增受测适配协议。

组件导出为AAC重建峰值保留限幅余量，最终仍实测≤−1.5dBTP；本期真实素材测试曾在旧0.8限幅后测得−1.49dBTP而被拦住，0.75限幅的同源音频实测−2.05dBTP。新参数/执行器另冻请求，旧成片及质量回执不改写。

## 参考理解的增量

采用Hypit“先理解整片，再检查具体动作，再回到整片验证”的方法，未整体搬入其Runtime。项目新增变化扫描和同源台词回看：保存实际PTS、源/帧SHA、局部活动与转场候选；围绕真实句/词时钟提取原生分辨率画面。候选窗口只帮助定位，不能代替语义判断；分析记录继续写整片论证、对象持续状态、进入/变化/离开与未看清的证据。

借鉴开源调研中的职责划分：制作流程、语义时间轴、动作组件和对外参数分开。现有Remotion、原包公开执行器与统一队列各自承担明确工作，没有把多个整套视频引擎叠加成另一条生产线。

逐项来源、适配分、具体借用与缺口见[61个开源项目分析](research/MOTION_TEMPLATE_FIT_20261101.md)，另有11项许可/交付特殊对照。该报告为一手README与元数据核验，不是61套运行验收。Hypit附加许可、lieflat的非商业starter范围与原包自身授权分别处理，不把方法借鉴等同于可整套再分发。
