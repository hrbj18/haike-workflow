# 高质量数字人工作流

用户于2026-10-20指定的固定呼叫名。适用于单人高清口播母版生成；这是数字人生成路线，后续字幕、素材和版式按本期指定模板处理。依据为 Codex 对话 `01a133d8-cebf-7d70-96bc-be719c885bf4` 的 V5.3.1 最新基线。本次完成规则登记和本地输入绑定，未新增云端生成或异机验收。

## 固定规则

- RunningHub 工作流 `2112180419025260546`，V5.3.1，Plus 48G请求（`instanceType=plus`）。保留四步采样、自然讲解手势、RealESRGAN超分，MKL颜色匹配关闭。长边1536是超分交付，帧率25fps。
- **每个独立生成任务最多45秒**，即最多1125帧。按实际完整配音的25fps时钟分段；不足45秒保持实际时长，超过45秒自动拆分，不能把45秒误当全片上限。该附件当前全片上限600秒，超过时先扩展并验证执行器。
- 首段使用本期参考图；后段继续绑定同一原始参考图，并以成功前段的原生尾帧PNG作为起始图。保持精确帧号连续，最终本地拼接并挂回完整原配音；不通过改变语速凑片长。
- 默认人物名称为**侯总图片**：沿用对话最后测试的侯总造型02及其四画幅图片。默认声音名称为**侯总音色**：映射该对话最后测试的供应商音色“天亮猴哥”，百炼 `qwen-audio-3.1-tts-flash`，原生1.15倍速，全文不换行、保留标点。这是本工作流的显示别名，不覆盖其他项目中同名侯总音色。
- 用户本次明确提供的图片、音色、倍速或完整音频优先；已有完整音频直接使用。私人音色编号、图片路径和哈希在根目录忽略文件 `.local/high-quality-avatar/defaults.json`；跨账号重新核验权限，缺少绑定时明确报缺项。
- 支持16:9、1:1、9:16、4:5，交付尺寸依次为1536×864、1536×1536、864×1536、1228×1536。未指定画幅时使用4:5。2026-10-20起本地默认4:5图片改为侯总文件夹内的3200×4000无灰边版本（AI扩图后放大导出，非原生4K生成）；路径和哈希见本地绑定。附件自带的历史3:4输入仍保留作来源记录。

## 调用与恢复

1. 新机器使用包内 `workflows/runninghub-high-quality/README.md` 和 `agent_cli.py`；图和参数真值为同目录 `capability.json` 与 API JSON。本机已有私人绑定时可读取根 `.local/high-quality-avatar/defaults.json`，其 `kit_root` 指向历史附件，不能当作新机必需路径。包内不带侯总私人图片、音频和音色；用户明确提供本次输入。项目及Agent默认性价比工作流，单次呼叫高质量不修改长期默认。
2. `doctor --workspace <本工作区>` 做离线检查，`plan --workspace <本工作区> --audio <本期完整WAV> --ratio <画幅> --image <本地绑定中该画幅的path> --segment-seconds 45` 读回分段及预算；后续 `run` 也显式传同一 `--image`，避免回落附件的历史补边图片。使用本工作区已有Python与FFmpeg。新文案先按本地默认音色配音；附件样例WAV只用于明确的样例测试，不替代新文案。
3. 云端预检核验工作流访问权、音色及消费级Key类型；Key从本机私有配置读取，不进入规则或素材绑定。沿用对话已验证的消费级 `NORMAL` Key，不能只凭环境变量名称判断Key类型。
4. 用户授权本期费用后，以固定任务名执行附件 `run`，每段不超过45秒并保存原任务ID、预算和产物。此附件现有入口仅为独立工作流测试；正式父视频生产仍走项目统一队列。工作流呼叫名登记不表示 Studio 普通口播已自动切换到此模型。
5. 恢复时读取原 `runs/<name>`，查询原云任务，复用已完成片段；受理未知时先查原任务，不重复提交。相同任务名保留冻结输入，替换素材使用新任务名。分段全部完成后本地合成完整片，检查尺寸、25fps、帧数、完整音轨、完整解码、接缝、口型与明暗闪烁，再交付视频及费用记录。

历史对话记录包含4:5约117秒分段片及其余三个画幅12秒测试，以及最新ID下33—37秒三条成片；这些是历史来源证据，本次不将其标为本副本重新实测。双人同图对话未在此基线验收，不能按单人规则直接承诺。
