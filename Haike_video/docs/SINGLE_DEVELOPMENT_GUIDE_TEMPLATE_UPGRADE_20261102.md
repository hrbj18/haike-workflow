测试复用已有完整口播、真实ASR和已有数字人，无新TTS/ASR/数字人付费调用，不循环或拉伸人声/人物，也不把旧口型配到新台词；既有授权配乐的明确循环单独留准备回执。新视频音轨为主钟；30.6秒、22.8秒人物出镜只是既有样片输入，不成为通用常量。模板动效、布局真值、审核与统一队列保持原入口，不能以成片拼接、旧MP4复制或新建旁路生产器代替模板复用。

4. **更新成功有明确含义。** 原1027走独立事务bootstrap，普通兼容1.2补丁走现有更新器；本次依赖迁移也只允许声明的精确1.2构建走事务bootstrap。安装后验证版本/工作区、精确预设和依赖，运行无付费局部渲染自检，分别记录程序成功与模板待导入/待绑定/可制作。应交付文件缺失或自检失败阻止成功并回退。已有同版本也要核对要求能力；本机配置问题不伪装程序缺陷。
