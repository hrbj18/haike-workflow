# Public components v2 candidate

Contract: `haike.motion-public-production/2`. Consumer: `backlot.motion_public_production_v2`; fixed executor: `backlot.motion_public_execution_v2`. Engines are `observed-controls/2` and `dark-remotion/2`. This is a new candidate, with no actual v2 media acceptance or complete distributable input fixture yet.

The original `/1` tree, requests and C source remain unchanged. `COMPONENT.json` binds this directory and the retained `/1` public upstream inventory. The old upstream HTML renderer, capture helper, tool and dependency descriptors are retained byte for byte. The dark runtime descriptor is also the original descriptor, including its original engine metadata: it describes retained external runtime bytes, not the new contract. No runtime binaries are copied or installed.

Dark source changes are limited to two visibility guards: reference mode retains its editor frame labels; other modes hide only the Timeline counter and S08 frame prefix while retaining their layout space. Media, activeFrame calculations, highlight/entry/exit/cues, six TSX files' other logic, fonts and audio remain unchanged. Project-owned TSX retains AGPL-3.0. Remotion, Chromium, Node, FFmpeg and npm dependencies retain their own license terms and notices. The independent observed-control source does not contain protected renderer or font programs.

Paper uses a linear eight-codepoint-per-second quote and delays attribution until typing settles. Its fixed consumer rejects windows too short for typing, attribution and the original exit. Poster uses the already acquired Geist Latin and public Noto CJK stack, measured title and quote parameters, and observed step states. Poster quote `props.lines` optionally supplies explicit line boundaries; joining those lines must reproduce `props.text` exactly. Other styles do not accept this quote parameter. The recipe example carries the observed three-line health quotation without changing its wording. No bitmap scaling is used to compensate for font metrics.

Existing title/prefix font probes support bounded parameter choices; they do not establish full paragraph/layout equivalence. Full line wrapping, paper's dense typing window, target frames, changes outside the two dark label regions, continuous sound/video and final export remain pending. `defaults.json` and `dark-v2/defaults.json` are versioned recipes, not executable full production inputs or new gallery defaults.

Use the controller's current concrete approval identity. Build and render require an internal zero-argument `_phase_guard` callable injected by the controller into the invocation; it is never accepted as JSON input or frozen request content. The executor calls it around subprocess/media commands. Missing callbacks, rejection, withdrawal or changed specific approvals fail closed. `full_decode: passed` is written only after successful whole-output FFmpeg `-xerror` decode, followed by the retained loudness checks.
