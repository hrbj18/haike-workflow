# 动效模板2 · 活力现场

文档类型：video-template-runbook。标准版本：video-template-v1。
模板规格：[规格](video-template-spec.json)。版本：**1.0.0**。稳定ID：`kinetic-field-v1`。
状态：**视觉定稿；16秒竖屏低清受控复用就绪**。2026-11-03记录用户确认“这个效果可以，固化为模板，叫动效模板2，名字你来取”。

## 入口与边界

呼叫“动效模板2”“活力现场”或完整名称均进入本模板。前端：数字人口播→选择模板→视觉模板库→模板画廊→动画模板。可播放已确认样片、读本手册、复制Agent制作指令；由Agent调用下述队列，不把视觉库ID传入普通口播表单。

`layout.json`是颜色、场景和时钟真值；`index.tsx`是几何、裁切、叠层与逐帧动作真值；`content.json`保存已确认示例文字，`input-contract.json`定义替换范围。`release.json`绑定定稿源及依赖SHA，`render.cjs`执行前核对。源码变化需恢复定稿或另建版本，不重新写哈希掩盖设计变更。

当前就绪范围为16秒、9:16、270×480、24FPS。更长口播由作者按完整声音改编并另存版本；不得裁掉后文、加速声音或重复人物凑长度。1080p/≥20Mbps、新稿连续听看、平台真机分别验收，不能从当前低清视觉确认推定通过。

## 固定设计

酸绿、钴蓝、珊瑚红、黑描边；五段依次为双画面分割变形、互动放大、照片接力、场所定位与人物、大人物收尾。顶部短题全程，真实素材为主；多个图层可以共存，主动作按拍先后出现。禁止口播原句堆上屏、空白文字页、过小主体或只换颜色冒充新模板。

参考MotionGit活力海报原版21–36秒的双媒体接力、胶带、主体揭示，独立竖屏重排；未复制原包代码或媒体。结尾文字组装使用本地Snapcn `TextReveal`，其他几何由本模板实现。

## 每期替换合同

新私有请求顶层固定为`contract`、`content`、`files`、`avatar_sync`、`rights`，contract值为`kinetic-field-request-v1`。

- `content`完整填写`content.json`的13个键。长度取`input-contract.json.text_limits`；中文约1字宽、ASCII约0.55。短主题、品牌、主体名、胶带、互动强调、照片标题、场所/楼层/地址、结尾标题和印章独立替换；新一期必须主动填写地址等信息。超长精简，不自动缩小字号。
- `files`的12个名称、种类和最短时长取`input-contract.json.files`。每项包含`path`绝对路径、实际`sha256`和`provenance`来源/预切时间。六路视频、四张实拍静帧、中文字体和16秒`sample.wav`全部齐备。旧文件名只是角色标识，新一期不必出现机器狗。
- `avatar_sync`固定为`{"host-close.mp4":[8,12],"host-open.mp4":[12,16]}`。两段人物按本期声音原速预切；实际同源证据与口型还需看帧，声明本身不能证明同步。
- `rights`保存本期使用依据。素材、声音和人物只在私有目录，不进入公共源码。

固定窗形和放大镜位置下，新素材先选段/预裁切，再看关键帧保护人脸、重要物体及细节焦点。当前不开放修改动作时钟、窗形和色板；确需改设计另建版本。

## 输入 → 动作 → 产物 → 检查 → 恢复

1. **版本和历史任务**：`node verify-release.cjs`校验源。先查本期已有episode/队列/产物，已完成阶段复用；缺少输入只补缺项。
2. **准备本期**：`python prepare_inputs.py --request <本期JSON> --data <全新私有目录> --ffprobe <已有ffprobe>`。全部标签/文件SHA/流/时长/人物区间通过后复制，生成`episode.json/public`。不修改原件或模板，不调用云服务；目标非空则停止，读取原任务恢复。`prepare.py`仅保留历史样片恢复兼容。
3. **构建**：项目Node运行`render.cjs bundle <本期目录>`。沿用Remotion4.0.506、本地字体与Snapcn兼容层。每期文字经episode.content传入同一Composition，帧预览和视频共用。
4. **关键帧**：现有backlot运行环境调用`Haike_video/scripts/kinetic_field_preview.py --install-root <明确安装副本> --data <本期目录> --phase stills`。统一队列领取本次自有暂停任务；别的任务运行时等待，不绕开队列。读取`stills-job.json`及其render.log恢复。
5. **实际检查**：查看29个关键状态，核主体、文字、交接、放大对象和人物。保存`design-review.json`：status为pass、identity精确取本次stills-job、images为所看图片path/SHA、observations至少三条具体观察。旧评审不能当新一期通过。
6. **渲染交付**：同一入口`--phase video`核源码、素材、包及图片评审身份后生成16秒MP4。检查384帧、画幅/音轨、完整解码、编码后画面与声音；AAC容器尾垫和视频时长分开记录。结果不明先读原队列，保留产物；高清另行适配。

本期完整声音原速，固定增益见layout.audio，不制造新配音。已确认样片的场所原片5.466667秒，末约1.2秒保留实拍尾帧、数字人持续开口；仅对该SHA保留复现例外。**新场所素材至少6.6秒**，人物至少4秒，不自动循环或冻结补不足。
