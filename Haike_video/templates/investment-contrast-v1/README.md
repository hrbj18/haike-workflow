# 招商撞色11—13 五秒视觉开发样片

设计：11紫柠圆场采用紫底柠黄与圆形/胶囊镜头；12朱红冰蓝采用冰蓝底、朱红横幅和横向不等宽双窗；13橙绿斜切采用森林绿底、橙色斜面和错位照片拼贴。与07细线剧场、08折面侧栏、09粗字阵列保持不同的主构图。

当前范围仅4:5、1440×1800、30fps、150帧、H26420M ABR；本地已有数字人及实拍复用，不调用云端生成、不发布。独立合同investment-contrast-five-v1，通过统一production queue执行。视觉源为index.tsx；数字人与实拍按独立图层处理，字幕时间取已核对源视频前两条ASR，0.16–2.56及2.88–4.76秒。第11圆形遮罩会裁切画面四角，预览需确认面部与产品主体。

11在2.9秒由人物大圆切换为门店胶囊和互动圆；12在2.5秒切换主实拍，人物全程保持；13在2.5秒由左窗实拍＋右窗信息切换为左窗信息＋右窗实拍。各原实拍在单片累计不超过4秒。

本文件为设计阶段说明，尚未作为30秒生产模板验收。声音使用已授权本地BGM/SFX、原人声截取0–5秒，尾部淡出仅音乐，不截断口播词句。连续听审/目标平台显示独立记录。制作结果及素材SHA见项目冻结request与quality.json。
