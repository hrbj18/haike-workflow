# 店长账号·实拍动效短片

文档类型：video-template-runbook  
标准版本：video-template-v1  
模板规格：[规格](video-template-spec.json)  
状态：`implementation + ready`，限定本机v001的技术、40帧视觉抽样及真实队列；连续听看、真机、异机及用户确认待验。  
最近核验：2026-10-26；24.6秒/738帧、8镜、1440×1800/30fps，产物范围以冻结项目证据为准。  
适用范围：4:5 店长账号无口播短片，实拍主导，独立音乐与动效音效。  
权威入口：[实现](index.tsx)、[布局](layout.json)、[类型](types.ts)、[适配器](../../backlot/studio_store_motion_showcase.py)、[项目入口](../../AGENT_GUIDE.md)。

这是项目自有的可编辑模板。MotionGit 公开示例只作为文字入场、窗口变化和阅读停留的参考；本模板不修改 `.motion`、不携带其受保护代码，也不声称与其原生工程直接兼容。参考观察、采用机制和具体设计见[视觉方向](VISUAL-DIRECTION.md)。

## 输入与参数真值

`index.tsx`、`layout.json` 和 `types.ts` 是画面、动效与字段的真值；适配器是输入门禁、冻结、队列和导出的真值。本页说明职责，不另存一套像素参数。

| 参数 | 职责与本轮边界 |
|---|---|
| `durationFrames` | 30fps 全片主时钟；母带须精确覆盖同一长度。本期短样 738 帧/24.6 秒。 |
| `shots[]` | 原素材安全文件名、原片秒偏移 `offset`、全片帧 `from/frames`、`contain/cover`、裁切位置、布局及文案。单镜至多 4 秒，主画面连续覆盖全片。 |
| `shots[].title/subtitle/kicker` | 可编辑的静音观看信息；按语义显式换行，超容量时调整文字或拆镜，保留数字、否定和限定条件。它们不是 ASR 字幕。 |
| `chapters[]` | 递增的章节起点与短标签；起点使用全片帧。 |
| `brand/location` | 本期真实品牌与地点，不沿用参考中的网站或示例产品承诺。 |
| `palette` | 画布、正文、辅助文字、蓝/橙重点和线条颜色。改色后重新检查实际编码帧的对比度。 |
| `motion` | 在实现允许范围调整文字/窗口入场、退出和线条描绘时长；保留稳定阅读区。 |
| `audio` | 本期 `master.wav`：48kHz 立体声 PCM16，包含音乐与音效。所有实拍音轨静音，无配音、ASR 或数字人输入。 |
| `fontAssets` | 按实现约定绑定安全平面文件名；使用字体前保留来源，改变字体须重验字宽、换行与关键帧。 |

[示例参数](props.example.json)仅说明字段和时间映射，未附素材、音乐或本期审核证明，不能作为可直接投产的示例包。

素材先保留原始文件，登记本次实际选段、原片 SHA、方向、代表帧和选用理由。最终合成回到原片，不使用索引缩略图或低清精剪替代。原片内固化的店招、活动横幅和人物保持原像素，画面不能被解释为未经确认的当期活动、免费服务或收益承诺。

## 当前操作

所有命令从单仓库根目录运行，使用当前副本的 Python。便携包应先按根安装入口初始化运行时。

### 1. 准备并核对输入

- `input`：本规格、本期 `props + sources + title` JSON、原片、`master.wav`、`audio-receipt.json`、`asset-review.json`，以及实际使用的字体。
- `action`：调用适配器的 `validate_props`；核对素材回执逐镜匹配本次源区间与 SHA，母带与完整主时钟一致，所有现场原声均被静音。源方向由媒体解码器按元数据处理，不重复旋转。
- `output`：所有必需参数已定的本期输入，及可定位的来源和实际观看记录。
- `gate`：主画面全覆盖、不重叠，取段不超过原片；文字容量与阅读时间满足门禁；没有旁白、语音或虚构 ASR；本次仅本地制作，发布为 `false`。
- `recovery`：补齐具体缺项，保留已选源文件与审核记录。修改取段或裁切后重新查看受影响画面。

### 2. 冻结并通过统一队列渲染

```powershell
Haike_video/.venv/Scripts/python.exe -X utf8 Haike_video/scripts/store_motion_showcase.py --input 本期输入.json --output-dir 本期交付目录
```

- `input`：通过输入门禁的本期 JSON。
- `action`：`prepare` 复制并校验原素材、冻结 props/来源/实现身份；`submit` 使用 `studio_investment_recompose` 的本地合成通道，合同为 `store-motion-showcase-v1`。指定原任务由统一队列执行器领取，再调用项目 `VideoCompose/Remotion`；不直接调用底层渲染绕过队列。
- `output`：项目内冻结请求、原队列编号、成片、技术 QA 与作品候选记录。
- `gate`：请求、源码、音频和素材身份一致；视频可完整解码，尺寸/帧率/帧数/时长符合冻结输入，视频流实测至少 20Mbps，最终音频真峰值不超过 −1.5dBTP。
- `recovery`：先读原请求和队列终态，复用已完成产物。未完成的本地阶段从原任务恢复；实现或输入发生变化时新建冻结版本，保留历史版本。本流程没有付费生成或真实发布步骤。

### 3. 检查原请求或恢复

```powershell
Haike_video/.venv/Scripts/python.exe -X utf8 Haike_video/scripts/store_motion_showcase.py --request 冻结请求.json --check
Haike_video/.venv/Scripts/python.exe -X utf8 Haike_video/scripts/store_motion_showcase.py --request 冻结请求.json --output-dir 本期交付目录
```

- `input`：本次实际返回的冻结请求路径和原队列编号。
- `action`：先用 `--check` 核对本项目与产物身份；通过后使用同一请求恢复或复制同 SHA 的已有结果。
- `output`：原任务的当前状态，或同版本交付文件。
- `gate`：不将新参数塞入旧请求；不覆盖不同 SHA 的已有成片；完成状态与实际文件同时存在。
- `recovery`：输入缺失时恢复同 SHA 原片；源码改变时重新冻结。本地渲染失败不会触发 TTS、数字人或其他云调用。

### 4. 视觉、动效与声音交付

- `input`：完整编码成片、冻结 props、技术 QA、实际帧和声音分轨。
- `action`：每镜查看入场开始、运动中段、稳定阅读和离场边界；核对标题、整机/门头保留、窗口变化及切口。完整播放检查真实运动和阅读停留；检查音乐/音效的开头、中间与结尾、AAC 真峰值和单声道折叠。设备外放和平台 UI 另验。
- `output`：逐项审核记录、实际播放范围、最终 SHA 与可播放成片。未完成的连续听审、真机与用户确认分别保留 `pending`。
- `gate`：交付声明只覆盖实际完成的检查。静态图、解码成功、非零音频或队列完成均不能代替动效和听看结论。
- `recovery`：定位到具体镜头、字段和输出时间，修改参数真值并生成新版本；只复验受影响与关联范围。

## 复用与交付边界

本轮先验收 4:5 本地短样；横屏、9:16、新素材、新字体或超出已测文字容量须独立复验。正式复用前核对规格就绪状态和对应 gate。项目队列接入不代表另一台机器、真实平台或用户艺术确认已经通过。

每期保留冻结请求、原片使用清单、音频回执、props、队列、技术 QA、实际看帧/听看记录与最终 SHA。私人媒体和运行数据留在项目忽略目录，公开源码只携带实现、规格和示意参数。

## 已知故障与恢复

| 现象 | 阻断依据 | 恢复与复验 |
|---|---|---|
| 素材缺失或 SHA 改变 | 冻结输入与源文件不符 | 恢复同指纹原片；有意换素材则新冻结并重看实际区间。 |
| 标题过长或短镜来不及读 | 参数容量/实际输出可读性未通过 | 按语义换行、简化本期上屏稿或拆镜；保留事实与限定词，重验对应镜头。 |
| 原片方向或主体裁切错误 | 实际帧与来源/布局不符 | 核对旋转元数据、`fit/objectPosition/layout`；重新预览后导出新版本。 |
| 混入现场说话声 | 不符合无口播合同 | 所有实拍保持静音，重新检查独立母带与导出映射。 |
| 运行完成但无可读视频或声音 | 技术 gate 不通过 | 保留原队列和日志，修复失败阶段；不要用完成文字替代产物。 |

维护触发：源码、布局、字段边界、字体、素材身份、时钟或混音策略变化后，重验受影响维度。本页不追加逐次任务日志，也不升级其他店长模板的验证范围。
