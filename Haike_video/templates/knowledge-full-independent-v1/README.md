# 独立知识讲解运行组件 v1

这是一份新写的可编辑实现，参考知识讲解公开的纸笔笔记、黑板粉笔表达原则；未读取、提取或复制两套 MotionGit 个人包的模板核心。原包缺少独立公开再分发许可，因此本组件使用独立身份，不声称与原包源码或逐像素表现相同。

`Board.tsx` 持有图解状态：问题转答案、连续步骤、对比两栏、真实证据窗口、引用、完整边界卡和邀请。动作按实际语音事件启动，完成后保留关系供阅读。纸笔版使用方格、便签与错位手绘边；黑板版使用低亮底、粉笔轮廓与描线。图解与字幕各司其职。原声不变速，实际视频原速、无循环，人物只显示已核对的同源窗口。

`index.tsx` 为 Remotion `KnowledgeFull` 入口；依赖仓库已有 Remotion/React 及锁文件。字体使用仓库 NotoSansSC 的 OFL 许可文件；每份作业将字体及完整来源按 SHA 冻结。无个人包、封套、私材、音频或凭据随组件分发。本目录新写组件按同目录MIT许可证分发；OFL 与第三方运行时保留原许可。

通过 `backlot/studio_imported_knowledge_full.py` 冻结并提交统一父队列。完整成片、实际画面对照及视听边界在各作业记录独立保存，安装或 schema 通过不能代替成片验收。
