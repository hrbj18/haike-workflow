## 输入、模块与真值

`types.ts` 定义开放字段，`layout.json` 与 `index.tsx` 定义几何、样式、状态和插值，适配器定义来源、时间、冻结与队列门禁。像素及动效取值从这些入口读取；[示例参数](props.example.json)仅演示安全文件名与字段形状，不携带私人素材或本期审核证明。

该示例只含 `props` 对象：七个连续场景、六项具名素材、十一条原时钟字幕及人物大框/小框时窗。运行时须将其放入本期 `{title, props, sources}` 输入并绑定全部真实文件与回执；不能把示例直接当作 `--input` 的完整生产请求。规格按复用组件登记元素，各场景只引用当段实际使用的模块；素材、字幕和人物变化仍须通过来源门禁。

| 层次 | 本期契约 | 复用边界 |
|---|---|---|
| 项目制作主干 | 已有稿件、干声、旧 ASR/cue、同源人物、实拍、混音和统一队列 | 音频原速连续，字幕沿原始时间，保留付费产物及回执来源链。 |
| 包级适配 | 本期素材身份、效果字段、字体/依赖、主时钟、画幅与能力声明映射到本模板输入 | 新包逐项声明输入输出、时间/资源依赖、受控槽、降级方式和验收范围后再接入。 |
| 效果模块 | `statement` 文字层级；`select` 选择同一卡并放大；`focus` 真实原片窗口聚焦 | 模块使用成片帧钟和声明的局部时钟；不调用新的声音或人物服务。 |
| 成片组合 | `scenes` 连续覆盖本期 600 帧，按口播语义选择模块和实拍 | 调整组合需重新冻结并核对全片覆盖、阅读容量、字幕与人物避让。 |

源音频取一段连续原速区间，母带由该干声与独立 BGM/SFX 合成，尾部仅补非语音时间。所有实拍与人物视频的内嵌音轨静音，避免重复人声。`master.wav` 按最终 30fps 帧钟精确覆盖全片；画面跟随声音，不拉伸声音迁就模块。

字幕只使用旧 ASR 的词/cue 时钟及经批准的显示文字，按语义短句控制在 18 字以内。源视频和图片中的招牌、横幅与人物是固化像素；新标题和字幕不能据此推定当前活动、价格或能力承诺。

`presenter` 绑定一条真实人物视频及其全局窗口，`presenterModes` 只控制该窗口内的大框/小框。未覆盖区间显示主视觉，人物不出现。大小切换保持同一个局部源时钟 `offset + (globalFrame − presenter.from) / 30`，不从头播放；25fps 来源按同一时间采样到 30fps 输出。

## 当前操作

命令从单仓库根目录运行。便携副本先按根安装入口初始化运行时。

### 1. 核对并冻结原声、字幕、人物与实拍

- `input`：本期 props/来源映射/标题、原干声及旧音频回执、旧 ASR、人物视频、实拍与封面、母带和本期来源审核。
- `action`：读回旧来源链和 SHA，核对连续音频区间与句末；比较 cue/词时钟、人物源偏移、实拍采用区间、封面身份及实际观看记录。只映射已声明槽。
- `output`：原速口播区间、精确字幕、人物全局/局部时钟、逐项素材与混音回执。
- `gate`：所有来源可定位且身份一致；无音频重排/变速；字幕有旧时钟依据且句子完整；人物模式处于真实同源窗口内；实拍已看且能覆盖原速区间；母带和输出帧钟一致。本轮不产生新 TTS、ASR、数字人调用，也不发布。
- `recovery`：补齐具体缺项并保留已完成素材；有意换音频、cue、人物源、实拍区间或实现时新冻结，不覆盖旧记录。

### 2. 通过统一队列制作开发测试片

```powershell
Haike_video/.venv/Scripts/python.exe -X utf8 Haike_video/scripts/motiongit_narrated_pilot.py --input 本期输入.json --output-dir 本期交付目录
```

- `input`：通过门禁的本期 JSON 和全部来源/审核文件。
- `action`：`prepare` 校验并冻结素材、参数和实现身份；`submit` 进入既有 `studio_investment_recompose` 本地通道，合同为 `motiongit-narrated-pilot-v1`；队列执行器调用项目 `VideoCompose/Remotion`。
- `output`：冻结请求、原队列编号、完整编码测试片、技术 QA 与作品候选记录。
- `gate`：600 帧覆盖三个模块及无人物/大框/小框状态；统一队列与实际文件对应；1440×1800、30fps、20 秒、完整解码及至少 20Mbps 视频流满足本期输入，AAC 真峰值不超过 −1.5dBTP。
- `recovery`：查询原任务和已完成本地产物，从同一冻结请求继续；渲染故障只修复本地阶段，不重新生成已付费声音或人物。

### 3. 检查与恢复原请求

```powershell
Haike_video/.venv/Scripts/python.exe -X utf8 Haike_video/scripts/motiongit_narrated_pilot.py --request 冻结请求.json --check
Haike_video/.venv/Scripts/python.exe -X utf8 Haike_video/scripts/motiongit_narrated_pilot.py --request 冻结请求.json --output-dir 本期交付目录
```

- `input`：实际返回的冻结请求路径与原队列编号。
- `action`：先校验素材、来源回执、ASR、实现和已有产物身份，再恢复同一任务。
- `output`：原任务当前状态或同 SHA 的已有结果。
- `gate`：身份未变且产物可读回；新时间线、新素材与不同实现使用新冻结版本。
- `recovery`：恢复同 SHA 的缺失文件；明确变更则保留旧工程和成片，新建版本继续。

### 4. 验收并交付

- `input`：完整编码视频、技术 QA、冻结输入、音频分轨及模块/人物边界采样计划。
- `action`：查看每个模块起止与动效中点、同卡选择到放大、聚焦窗、文字层级、人物大转小与消失边界；检查字幕语义及避让。完整播放核对声音、节奏、字幕、人物口型与连续源时钟，另行记录设备外放和目标平台呈现。
- `output`：实际看帧及连续听看范围、逐项结论、最终 SHA 和可播放交付。
- `gate`：模块和成片分别有结论；来源音轨相关性、静态帧、技术成功与队列完成不代替口型/听审或动态验收。每个适用维度有事实证据；抽样不推定全片、换包或异机通过。
- `recovery`：定位具体模块、元素和输出时间，修改参数真值后保留旧版，只复验受影响和关联范围。

## 故障与维护

| 现象 | 阻断依据 | 恢复与复验 |
|---|---|---|
| 人物变大/变小后嘴型跳回 | 局部时钟与全局音轨映射不一致 | 保持同一人物源与 offset，复验整个真实窗口及切换中点。 |
| 字幕位置正确但台词错位 | cue/词时钟、音频 SHA 或区间不符 | 恢复旧 ASR 来源链，按原时钟重新分句，不重新付费识别。 |
| 实拍/人物出现重复人声 | 视频内嵌音轨进入母带之外 | 保持原片静音并检查导出映射，重验整片声音。 |
| 模块时间留空或超出真实素材 | 场景覆盖或源区间不足 | 改选已审素材/模块组合，新冻结后核对全部相邻边界。 |
| 新包要求改变音频主时钟或生产路由 | 不符合本期包级接入边界 | 记录该能力缺口，先完成该包独立适配与验证，再扩大声明范围。 |

实现、布局、字体、口播/字幕/人物来源、素材、模块字段、主时钟或混音策略变化后，重验受影响维度。公开目录仅保留实现、规格和示意参数；私人来源、付费回执、原片、成片与逐次日志留在忽略目录，不追加为通用验收事实。
