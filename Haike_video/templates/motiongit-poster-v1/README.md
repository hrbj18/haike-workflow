# 活力海报可编辑模板

本模板沿`motiongit-poster-story-v1`使用用户自己的`vibrant-poster@2.7.13`原包，调用官方`poster-kit`公开控件。五组为逐行巨字、胶片照片、扫描视频、立体轮播和箭头收尾。字段真值为本目录`profile.json`，布局及完整时码编排真值为`backlot/studio_motion_poster_session.py`。

在动效模板工作台选择本模板，改画面文案、三张照片、四路真实视频、配乐及完整口播；选择4:5并保留默认不出镜。人物隐藏只改变画面显示，完整口播持续播放，当前共享源合同仍核验人物同声源。新声音及人物必须通过现有来源阶段，模板不隐式付费生成。

来源代表帧检查→五组编排及素材区间检查→统一队列生成同画布有界预览→逐图审核→保存命名变体→统一队列完整导出。保存变体不会伪造或继承旧审核、付费任务。换内容后重新检查阅读停留和素材长度；不足时阻断，不循环短片、快放原声或截掉整句。

4:5由公开portrait和逐控件area重排后，在同一1080×1350窗口输出1440×1800/60fps。完整声音是主时钟；字体、字幕字框、三张胶片完整阅读及收尾必须实际检查。技术检查包括至少20Mbps、AAC48k双声道、完整帧钟、真峰值和全解码。实际本机/移位验收、样片和版本见根`docs/STABLE_THREE_TEMPLATES.md`指向的交付记录，不能外推为任意素材、任意时长或另一台物理机已实测。

首次环境随私人原包、合法示例输入和固定离线依赖部署，移动后由portable准备/启动重新绑定路径。包登记只接受同摘要本地文件，已声明离线依赖的安装缺失时应报错，不下载大依赖。程序和私人素材分开；更新、恢复及损坏包处理见根`docs/APP_UPDATES.md`。失败保留原任务和已生成源，从原编号恢复。
