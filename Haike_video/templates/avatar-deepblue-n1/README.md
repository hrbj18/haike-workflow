## 身份与真值

模板 ID 为 `avatar-deepblue-n1-v1`，Remotion composition 为 `HaikeDeepblueN1`。本实现以[原 N1 手册](../../../Haike-Videohub/agent-runbooks/数字人口播模板——深蓝视窗N1.md)的测量和显示规则为参考；新组件独立实现，不依赖旧模板4组件，也不继承其验收状态。复制的参考手册保持原有“待验证”结论。

几何、颜色和动效数值只编辑 `layout.json`。规格的元素框是同一配置和组件计算的只读投影，`evidence` 绑定配置 SHA-256；配置变化后重新派生投影并重验受影响画面，不能单独修改规格中的几何来改变渲染。字体、内容与源比例变化后，仍须查看真实渲染帧。

规格中的15秒及四个等长场景用于当前开发演示覆盖，不限制普通作品片长。正式制作使用实际主音轨为时钟，场景和字幕跟随音频。演示若使用静音音轨、人物循环或合成信息图，必须在演示输入/来源清单显式声明；这类演示不能证明连续口型、语音同步或真实新闻内容已验证。

本次 `ready` 只覆盖当前工作区、实现版本和验证矩阵的输入范围。新人物、极端字长或不同素材比例仍需本期画面检查；新云生成与ASR按原流程单独验收。迁移电脑时重新核对本地证据、字体和环境，不能只复制规格 JSON 沿用本机通过结论。

公共模板卡片和四模式预览使用 `public/assets/n1-public-*.png` 实际帧与 `n1-public-sample-v1.mp4`。可复现输入及脚本见[公开样片说明](showcase/README.md)，产物来源清单为前端 `public/assets/n1-public-provenance.json`；均由同一N1组件及布局渲染，只有通用几何人物和源码合成内容，无私人媒体和云调用。旧私人样片、四帧及封面仍按原SHA保留在根 `.local/release-private-previews-20261016/`，不进入前端或通用源码包；2026-10-15浏览器记录只支持历史页面，当前公开样片页面另做回归。

## 输入与受控替换

工作台选择“深蓝视窗 N1”；已有数字人制作流程继续提供人物、文案、声音和字幕。模板配置写在 `input.n1`，实际类型、边界和缺失处理由 `backlot/studio_n1.py:settings()` 检查。正文仅说明字段职责：

| 字段 | 用途与边界 |
|---|---|
| `titleLines` | 三行主题，首行暖黄、其余白色；空配置从本期标题派生，长度上限以校验器为准 |
| `sourceLabel` | 真实素材来源，允许隐藏；默认网络来源声明只适用于相应素材 |
| `brand` / `englishLabel` | 自有品牌胶囊和淡英文；英文允许为空 |
| `emphasis` | 字幕静态黄色重点词，保持逐句字幕时钟 |
| `scenes` | 按时间排列的四模式画面安排；未安排区间回到主持人，不能与 AI 分镜同时指定 |
| `scenes[].kind/start/end` | `presenter/material/screenshot/data`；全片秒、左闭右开，结束不能超过实际主音轨 |
| `assetId/fit/offset` | 素材或截图使用项目资产 ID；`offset` 是源素材起点，截图固定 contain，视频不足会阻断 |
| `dataLabel/dataTitle/rows` | 仅数据模式，纵向列表；事实、单位和来源由本期审核 |
| `highlights` | 仅截图模式，`x/y/width` 相对原图归一化，`start/duration` 为场景局部秒；随截图适配并在字幕下层 |

API 的受控资产引用使用 `assetId`，不把本地绝对路径或任意 URL 当作输入。截图固化的内部文字不能通过模板文字槽编辑。画面中的人物/视频视觉层静音，主音轨独立播放一次。普通生产不使用未经声明的循环或拉伸补齐不足视频。

## 当前操作

### 1. 冻结输入

- input：规格、配置、当前草稿、人物/音轨/字幕、项目资产及现有任务。
- action：读回规格与配置哈希，调用工作台草稿/报价前校验；核对素材来源、场景长度与本次授权。
- output：确定的本期输入与已有任务复用结论。
- gate：所有启用模式必需字段可解析，主时钟和资产身份明确；未知结果的付费任务只能按原编号恢复。
- recovery：补齐缺失字段或资产后重检；替换一段画面不重新生成已完成的人物视频或声音。

### 2. 开发样片与公共预览

- input：已确定的开发演示配置、已有本地人物素材、四模式覆盖计划。
- action：运行公开样片复现脚本，使用自写SVG及手工演示字幕，由未修改的实际N1组件做离线开发渲染；从同一成片抽四模式实际帧。不是生产队列提交，不登记正式作品，不使用私人媒体。
- output：15秒无音轨MP4、四张实际帧、源码/实现/工具/媒体SHA来源清单及完整解码检查；前端提供实际样片播放下载。
- gate：核对各模式、标题入场、圆框互斥、截图红线、数据逐行显入与收尾实际帧；技术及视觉分别记录。公共前端核对四图切换、原样片播放和下载绑定。无声与手工字幕不证明真实语音或口型同步。
- recovery：按公开来源清单读回已有文件，修改输入或布局后显式重制并更新SHA白名单；私人历史证据只从忽略目录读回，不放回public。修正本地渲染不重发供应商任务，首次短样不自动升级其他验证维度。

### 3. 普通作品与交付

- input：就绪规格和对应 gate、本期完整输入、用户生产授权。
- action：工作台选择模板并提交现有统一队列；读回原任务与产物，按验收量表检查。
- output：作品、版本与本期输入/规格身份一致的成片和 QA。
- gate：受控生产前先满足规格就绪和本次动作门槛；完整解码、全片画面/音频、连续听看及适用平台检查各自有结论。当前开发演示未覆盖的项目仍保持待验证。
- recovery：先查询原队列/网关任务，保留完成资产，从本地合成或具体失败场景恢复；正式发布另按用户授权。

## 静态检查与验证边界

在工作区根目录运行（Python 使用本副本虚拟环境）：

```powershell
.\Haike_video\.venv\Scripts\python.exe Haike-Videohub/verify/check_template_standards.py --spec Haike_video/templates/avatar-deepblue-n1/template-spec.json
.\Haike_video\.venv\Scripts\python.exe Haike_video/templates/avatar-deepblue-n1/verify_spec.py
```

标准检查器核对规范依赖、schema、元素/槽/时间引用和证据文件哈希；`verify_spec.py` 逐项比较元素框、名义字号与唯一配置。配置修改后使用同一命令加 `--refresh` 更新只读投影与配置身份，再运行两项检查。实现计算变化时同步检查投影公式。静态检查不检查实际文字测宽、音画同步、平台 UI 遮挡，也不能用独立渲染证明统一队列端到端通过；每次真值变化须重验受影响画面。

| 维度 | 当前范围与解除条件 |
|---|---|
| 规格/静态 | 2026-10-16新增公开样片证据后，标准依赖、`--spec`、投影及公开SHA/媒体验证均通过；结果在 `.local/release-regression-20261016/n1-public-checks.json`，旧检查记录保持历史身份 |
| 技术 | 公开开发样片1080×1920、30fps、450帧、15秒、无音轨且完整解码；其来源和历史私人15秒样片、普通主持人5.133333秒/154帧分别记录。公开样片不使用私人素材、云调用或真实队列 |
| 视觉 | 公开样片亲看四模式实际帧，动效按本次抽样另记；历史私人样片的四模式及8张动效帧、普通主持人2.5秒帧保留原范围。任意人物、素材比例或最长文本未推广验收 |
| 前端 | 当前公共四图均为同一成片实际帧，恢复公开样片播放下载，须随本次交付浏览器回归另验；2026-10-15私人预览交互只保留历史范围 |
| 连续听看 | 静音演示不验证配音、口型及同步；有声作品需实际连续播放 |
| 目标平台/真机 | 未检查真实发布平台时保持待验证；本地窄屏页面不是平台真机验收 |
| 用户确认 | 待用户确认当前样片版式 |
| 生产接入 | 示例和普通主持人合成均经真实统一队列完成并登记作品；普通测试无新增报价/云任务、字幕关闭。只证明本地合成与登记，不证明新云生成、ASR或正式发布 |

历史证据位于工作区 `.local/n1-showcase-20261015/`：`verification.json`（冻结样片技术）、`animation-qa.json`（实际动效看帧）、`normal-smoke.json`（普通合成队列）、`ui-qa.json`（旧私人预览交互）。原样片及四张真实帧现存于 `.local/release-private-previews-20261016/`，规格仅更换证据位置，媒体SHA未变；该目录的 `manifest.json` 记录保留身份。报告中的旧public路径为历史定位，当前读取以规格新路径为准。静态、视觉、连续听看、真机及当前公共前端结论保持独立。

## 恢复与维护

标题溢出先压短本期内容；截图被裁先核对 contain 及来源区域；人物重复显示检查模式与圆框互斥；红线漂移核对原图归一化坐标和源素材比例。改配置、字体、主时钟、源比例、字幕和事件后重验相关模式及切换。

本目录 README 是新实现的操作契约；原正式 N1 手册仅作为参考来源，不在本次迁移中改写其核验结论。运行产物与逐次证据留在工作区忽略目录，规格只绑定所需文件。用户上传人物和声音不随模板公共代码分发。
