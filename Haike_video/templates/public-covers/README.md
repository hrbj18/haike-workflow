# 随 main 源码交付的成片封面

此目录保存18套首选模板上次已完成视频的实际画面，复用当时选定的封面；模板10、11沿用此前选好的59.5秒片尾截帧。图片原字节复制，不重新渲染视频、不换素材重做演示图。按用户要求随源码提供这些成片封面，完整视频、声音、私人路径及绑定留在本机。

同时携带43张固定模板的原有封面：40张与20261027原版ZIP的恢复摘要一致，图文、访谈7和任务场景沿用之前已交付的现存图片。另5个基础制作模板由前端原有静态资源展示。固定模板优先保留用户本机绑定，缺少时使用这里的原图；本轮不重新制作封面。

`manifest.json`按画廊ID绑定当前选择版本、图片文件名、SHA256、大小、尺寸和来源成片SHA/版本。来源来自2026-11-04已锁定的18条完整高清有声视频；其中轻盈一体、纸感扩展、科技控制台、活力海报保留的是原成片版本，与当前公开制作适配版本分别记录。封面展示原成片效果，不宣称同输入复刻、连续听看或另一台电脑制作已经通过。现有组件、字体及画面素材的原许可和署名继续适用；这些封面不重新许可原素材。

动效画廊优先使用摘要匹配的成片图片，防止旧安装中的通用替代图覆盖正确样式。本机原封面仍通过“查看本机原封面”访问，样片和绑定文件均不改写。固定模板继续优先使用本机原封面。图片缺失或摘要不符时不将其当作已验证的公开样式封面。

源码升级会直接取得本目录，无需等待Release资源包。构建前端后，实际核对 `/api/studio/template-library` 的18个首选、43个固定模板及逐个 `poster` 请求；每图应可解码、摘要匹配且样式对应。封面通过与运行依赖、实际准备、完整出片分别验收。

新增或实质修改模板时，从对应实际成片选取已查看的代表画面，保留成片身份和截帧依据；不能用替代素材新做样式图代替已有成片。修改图片须同时核对对应模板版本和清单身份；保留旧用户原文件。
