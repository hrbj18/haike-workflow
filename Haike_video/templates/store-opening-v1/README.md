## 字体和文字

必需fontAssets固定为display.ttf、body.ttf、latin.ttf。HaikeDisplay是真实Smiley Sans Oblique400，保留内置斜角，fontSynthesis为none；HaikeBody为Noto Sans SC变量100—900，使用700/800；HaikeLatin为真实Exo2 Italic变量，使用800。FontFace、document.fonts.load与delayRender全部成功后才解除渲染阻塞，缺失文件直接失败，不悄悄回退系统字体。

大字采用显式语义分行，不用自动换行补救。字组进入用12帧横向遮罩显现与48px位移，随后稳定停留；不循环抖动。正文字幕64px，375px视频宽等比约16.67px，使用高对比的自适应底板；23/24彩色互文仅用于大字，正文不依赖低对比双色。地点和站名同级64px，当前原生375px代表画面已实际复验可读；数值真值仍以源码Location为准。

## 操作与恢复

1. 已批准音频、ASR、素材、人物和真实字体 → pipeline_redesign.py draft staging → props与public副本 → 核对SHA和主时钟；draft不生成伪crop pass。
2. 当前源码、草案props和明确帧计划 → 唯一native PNG执行者渲染 → 原生1440×1800 PNG、375px联系图和文件SHA → 实际看开头、每种状态、人物头顶、最长字幕、权益和结尾；失败只修受影响本地布局/裁切。
3. 当前新裁切报告与实际proof → 统一ProductionQueue prepare/validate新冻结请求，核对已看草案props和原素材字节完全一致 → 作者将实施规格限定ready到这五个新请求，并绑定实际作者/总控视觉回执 → full-render gate；不能重用v001冻结输入或通过状态。
4. 相同冻结版本 → 原生完整合成与20Mbps档输出 → 读回视频流码率、尺寸/帧率/帧数/时长、AAC峰值及全解码 → 当前最终视频另做实际抽样；音频、连续听看、平台真机、用户确认分开记录。

保留已完成的付费配音和人物，局部改版不重新生成它们。源文件、字体或实现变化必须新冻结；正式发布须本期明确授权，本期仅制作交付。

本期完整输出共4620帧/154秒，均1440×1800/30fps，实测视频流20,493,595—20,494,373bps，达到20Mbps。AAC格式/峰值、全解码和源SHA检查通过；01—03由material_shot_plan、04—05由opening_redesign_audit实际看完全部最终编码采样联系图。此项没有替代连续播放听辨、适用音素口型或手机平台验收。
