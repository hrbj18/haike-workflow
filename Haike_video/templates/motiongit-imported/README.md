# 已导入 .motion 的模板库入口

文档类型：template-library-guide。这是原包的发现与复用入口，不代替每包的参数规格，也不提升任何模板的验收状态。

导入的个人原包保存在本机私有目录，画廊从已导入登记自动生成卡片。打开卡片可看已明确绑定的本机开发样片，再点击“打开制作页面”定位到该包。没有样片时明确显示暂无预览；原包名称与控件数量不证明已经成功制作。

卡片区分：待核验仅检查、已核验仅参数编辑、开放制作接口。只有既有生产适配器支持的公开协议才显示开放制作接口；未知版本仍可保留和检查，不能靠改状态直接执行。查看画廊不会执行原包、下载依赖、调用配音或创建制作任务。

## 制作与复用

1. 打开对应原包，读取此包实际schema、控件、素材槽与制作说明；核对版本、授权和支持范围。
2. 在该包的“已保存草稿”选择已完成布局，点击“复制为新视频”。复制保留镜头和素材绑定，原期次保持独立。没有合适草稿时按该包已开放路线新建。
3. 换入自己的完整声音、实测字幕、已审素材及可选同源人物，按本期口播编排。横竖比例以该包实际能力为准；不把素材裁小或循环人物代替重排。
4. 通过参数、来源与主时钟检查；motion-kit实际核对计划后再生成预览，逐张核对预览后由统一队列导出。knowledge-story-v1按自己的句级证据与预览合同执行。绑定参数变化会产生新版本。
5. 技术、实际画面抽查、连续听看、口型和真机分别验收，成片进入作品中心。历史样片不证明新稿已经通过；重试恢复原任务和已付费产物。

画廊只投影名称、版本、声明的控件数量和入口，不向浏览器公开个人封套、密钥、原包路径或完整默认参数。个人原包、受限字体与素材不随公共源码分发。样片/封面由私有绑定明确指定，画廊不会猜测文件名并自动公开素材。

各路线的版本边界与HTTP/CLI恢复合同见[原生接入说明](../../docs/NATIVE_TEMPLATE_PROTOCOLS.md)。后续同协议原包可在导入/核验后自动进入画廊与编辑入口；新的执行协议仍需独立适配和实测。
