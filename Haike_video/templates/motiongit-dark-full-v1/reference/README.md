## 必须保留的关系

- `s02→s03`必须相邻。九格中央素材与放大的主素材是同一实体，源视频保持1x连续时钟，不能放大时换源或从头播放；末尾音乐riser和whoosh也连续交付。
- 每个主组是atomic，单组不等于一个短转场。短片选3至4组时保留组内完整阶段；若不选`s02`，用独立审阅组代替依赖中央九格的`s03`。
- 模板是多底色世界：开头紫蓝渐变，主体近黑，`s04/s07`纸白，`s06`电蓝。不能以统一黑背景代表完整原片。
- 组内入口、时间码、品牌角标使用最终输出时钟；源码source时间与最终拼接时间分开。独立审阅的1.6秒位移必须在plan中显式表达。
- 原演示中图表/COMPOSE/CONNECT是带内部设计的媒体。项目替换时须登记图中固化内容，不能声称图内英文文字自动可编辑。需修改的业务界面信息应作为独立UI数据或重新制作媒体输入。
- 公开原生最短时长不是整组可任意加速。动作受保护阶段与实际媒体时钟分别约束，安静阅读区可以按公开合同扩展。最短帧数列表见`observation.json`。
