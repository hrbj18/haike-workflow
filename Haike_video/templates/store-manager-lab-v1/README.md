# 店长账号新风格14–17

Creative Production用于广告叙事与关键帧比较，frontend-design用于颜色、字阶和结构设计。对象是附近居民，目标是把屏幕里的机器人与可到店体验的现场连接起来。四条统一用已确认口播第一句完整6秒，1440×1800/30fps/实测视频流≥20Mbps。不是完整30秒模板验收。

## 技术与复刻

index.tsx为几何和动效真值。输入字段style14–17、durationFrames180、avatar、audio、shots、captions；每条实拍≤4秒，left/right轨覆盖0–6秒，源offset以秒计，画面静音，人物沿全局时钟。字幕58px微软雅黑900，x55/y1558/w1330/h142，单行，整句6帧移动6px后静止；不使用发光和多层描边。地址底部45px/30px。主标题是画面主题，不覆盖同步字幕。

音频使用天亮猴哥第一条已确认配音0–6秒，不再变速；音乐−5dB、人声−2.5dB，原生speech-led-v1侧链与limiter，配乐末0.45秒淡出。dong首字幕0.68秒/−15dB，whoosh于3秒切换峰值对齐/−19dB。原音和母带及实际测量结果随冻结项目保存。

原生适配器backlot/studio_store_manager_lab.py；与旧模板分离，旧源码不改。prepare→submit→ProductionQueueWorker.run_local_recompose；失败查原队列，禁止直接绕过生成最终交付。CRF1高保真中间片后20.5M CBR/2M缓冲（短样留码率测量余量），最终视频流至少20M。不是源素材无损编码；不改写原片。

通过后的request由scripts/store_manager_template.py --request <path> --check读回；去掉--check复用归档，--fresh重新冻结当前实现。默认正式目录读.local/store-manager/defaults.json；本轮短样放其下模板测试子目录，避免混入正式全片。平台发布和主观设备听审待验。
