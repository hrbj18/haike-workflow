## 二、路径收口：新增 `_paths.py`

15 个脚本全部改为从同目录的 `_paths.py` 取路径，**零硬编码**。设计对齐两条既有约定：

- `contracts/layout.json` —— 「任何自动化脚本都必须按本文件解析路径，不得硬编码」
- `lib/paths.py` —— `REPO_ROOT = Path(__file__).resolve().parent.parent` ＋ 环境变量覆盖

```
_paths.py
parents[0]  scripts/template_video/
parents[1]  scripts/
parents[2]  Haike_video/         -> HAIKE_ROOT
parents[3]  四仓根                -> VIDEOHUB_ROOT
```

可覆盖的环境变量：`VIDEOHUB_ROOT`（新增）、`OPENMONTAGE_PROJECTS_DIR|MUSIC_DIR|MODELS_DIR`、
`VRF929_FACE_MODEL`、`TEMPLATE_VIDEO_WORK`、`FFMPEG_BINARY`。

## 三、迁移中实测到的两个陷阱（已写进代码注释与 `docs/pitfalls.md` 25/26）

1. **`dirname(__file__)` 当工作目录会错位** —— `qc_ep.py`、`_preview_ep.py` 原先靠"脚本与数据同目录"
   才把 QC json 写对；迁走后该表达式指向脚本目录，产物会**静默**落到错误位置。已改 `WORK = str(WORK_DIR)`。
2. **cv2 5.0 读不了含非 ASCII 的路径** —— 对 `D:\刘宇钊\...\yunet.onnx` 报 `Can't read ONNX file`。
   解法是**模型留项目内**（可入库）＋ `_ascii_safe()` 运行时镜像到 `%LOCALAPPDATA%\videohub-models`。
