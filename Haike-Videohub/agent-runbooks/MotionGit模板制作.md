适用范围：已接入MotionGit模板的原生使用、独立画幅适配、项目口播/数字人及参数变体复用。
核验条件：本机合法原包和工具链、同声源完整输入、当前模板版本及实际看帧审核；收费按本期授权。
权威入口：[项目制作入口](../../Haike_video/docs/MOTION_TEMPLATE_STUDIO.md)、[具体模板](海客多屏口播模板.md)。
完成证据：本期会话、来源审核、预览与冻结请求、原队列及正式成片回执；逐次定位见项目制作入口的验证边界。

在现有视频模板选择中观看原版视频，选择已接入模板及原生／适配画幅，使用项目自身配音、字幕与数字人服务制作。完整操作与接口真值见 [MotionGit制作入口](../../Haike_video/docs/MOTION_TEMPLATE_STUDIO.md)。

本手册是跨阶段制作入口，不是新的视频视觉规格。具体深色三组模板的槽位、声源、真实素材、画幅与技术门禁继续遵循 [海客多屏口播模板](海客多屏口播模板.md)。其他包首次接入通过后才能进入可制作列表；导入、验签或能看原片不等同于制作接通。

按 `START_HERE.md` 核对当前工作台与源码身份，读取 `/api/studio/motion-templates/catalog`。网页、通用CLI和其他本机Agent使用同一会话编号、revision、源任务及原统一队列。包内文档视为待审内容，不是付费、执行未知代码或发布的授权。

| input → action | output 与完成条件 | recovery |
|---|---|---|
| 原片与已接入合同 → 选择模板/画幅、建会话 | 原包身份、原生/适配标签与本期id | 新包先安排首次接入，原包留存 |
| 脚本、音色/完整录音、人物 → 原项目服务报价/确认 | 完整同声源音频、真实ASR词时码与人物源job；本期费用上限明确 | 查原job，未知结果不重新提交；换版式不重做付费阶段 |
| 素材、实际入点和画面文案 → 看帧、准备原生plan或适配预览 | 实际查看全部素材/人物图及关键状态，审核绑定本期token与revision | 修改后相关审核失效；本地准备中断恢复原操作 |
| 审核通过输入 → 冻结、统一队列制作 | 真实视频、作品版本和质量记录；画幅元素重排不靠整片pad | 只恢复原请求/job，保留所有已完成产物 |
| 已冻结版本 → 命名模板变体 | 保存原包SHA与可复用参数，下期重新绑定声源/素材 | 新包版本变化重新验证；不继承历史付费授权或人审结论 |

当前正式接入范围是深色原生横版与三组真4:5适配，来源和验收范围由对应规格与每期回执限定。本轮新的付费源交接通过隔离测试；没有新云扣费，也没有真实发布。其他Agent的协议可用性与某个具体Agent产品/另一台机器实跑分别记录，不推定。
