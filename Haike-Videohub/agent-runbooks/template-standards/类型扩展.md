# 视频模板类型扩展

文档类型：reference。
标准版本：video-template-v1（v1）。

**模板包含下列元素能力或流程**时加载对应扩展；可以组合多个。先满足[通用编写标准](../视频模板编写标准.md)，再把本文件的适用要求写入规格 `extensions` 并加入[验收量表](../视频模板验收量表.md)。类型标签用于触发要求，不限定视觉风格或生产引擎；同名模板的既有路由继续有效。

核心类型 ID 为 `avatar`（口播）、`graphic`（图文）、`chart`（图表）、`tutorial`（教程）、`material_edit`（素材剪辑）及 `custom`。`template_type` 声明主要类型；`extensions` 是对象，以类型或模块 ID 为键保存各扩展对象，允许额外模块。类型名称不排斥其他元素能力。

## 口播扩展

触发：真人/数字人说话、旁白主导或字幕按语音编排；没有人物时仅启用适用的语音项。

- 声音：声明主时钟、音轨来源、原声/旁白/BGM 的混合与静音规则，字幕依据及偏差容限。音频为主时钟时，画面和字幕按实际音频时长编排。
- 人物：声明外框、遮罩、裁切与主体保留范围；换人物时区分固定外框和可校准裁切，校准字段与允许范围进入 slots。
- 内容：声明文案、分句、强调词、字幕换行/读完时间及口型需要达到的程度；语音未生成时估时写为规格阶段未知或估计依据。
- 验收：长短句、停顿、字幕、人物主体与口型适用项、素材/人物/字幕避让；连续听辨声音与同步。短样不证明换人物或全片均通过。

## 图文扩展

触发：图片、截图、文字卡或固定信息板构成主要画面。

- 声明图像来源、卡片结构、编辑文字与固化内嵌内容边界；明确证据裁切、素材适配和局部强调规则。
- 声明标题/正文/注脚的信息层级，长度与换行约束，素材最少数量、停留/循环规则及缺素材处理。
- 含事实陈述时记录事实与素材证据的对应关系，未知事实标明影响范围；事实待核验状态不进入已核验内容声明。
- 验收：最长/最短内容、图片尺寸差异、裁切后关键信息、读完时间、全片卡片顺序与平台小字可读。

## 图表扩展

触发：图形编码数据，或数字变化、统计对比构成论点；装饰图形只适用通用元素规则。

- 声明数据来源/版本、单位、时间范围、缺失值与计算方法；图表文字、图例、轴、标签和标注区分可编辑与固化内容。
- 声明编码映射、轴范围/基线、排序、颜色语义、舍入、重点标记及动画期间数值状态；数据槽定义允许范围和异常行为。
- 验收：原始数据到画面的值一致、标签可读、轴/单位完整，极值/空值/零值适用边界；动画不制造未声明的中间数据结论。

## 教程扩展

触发：按步骤展示操作、软件 UI、代码、屏幕录制或指示性标注。

- 声明演示软件/版本、初始状态、步骤顺序、每步完成条件、输入/输出及失败恢复；素材录屏中的动作与本次实际操作区分。
- 声明指针、圈选、放大、提示卡与 UI 的依赖关系，裁切范围、点击/结果/讲解的时间对应及必要停留。
- 验收：按顺序可复现教程结论；标注对象准确，UI/代码未被遮挡，步骤跳转与配音同步，关键状态和失败分支范围明确。

## 素材剪辑扩展

触发：选取并组合已有视频片段、现场原声、旁白或镜头序列。

- 声明原素材身份、选段依据、局部截取范围到全片时间的映射、速度/循环/冻结/转场规则及素材不足行为。
- 声明原声、旁白与视觉可独立编排的关系；事件/论点到素材证据的对应，引用范围与来源信息。
- 验收：切点、动作/语义连续性、引用上下文、音轨衔接与同步；素材不足保留缺口及补齐要求，不用未声明的拉伸/循环覆盖。

## 自定义与组合扩展

上列未覆盖的能力使用自定义 extension，包含稳定 ID/版本、触发条件、增加的字段和约束、当前实现入口、验收项及证据要求；继续使用通用元素、slots、证据和验证维度。三维场景可扩展空间坐标、镜头与投影，程序生成流程可扩展求值顺序和状态；它们仍需说明如何映射到最终画布、时钟与验收对象。声明每个扩展的采用原因与不适用部分。

组合扩展冲突时，写清涉及字段、本次选择、理由与验证范围；每个属性保留唯一真值。仅声明 extension 名称不算完成，适用要求全部写入规格、操作和验收后才完成加载。
