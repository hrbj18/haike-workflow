## 触发与输入

用户呼叫“深色立体完整模板”时进入上述手册，不替换为旧同卡点击素材墙或单纯转场库。规格为implementation；执行前读取其当前stage和对应gate。specification阶段只做已授权、有确定参数的开发验收样片；受控正式复用要求ready及对应输入门禁。

已有完整音频＋素材：准备同一WAV真实词时码、看帧区间、素材SHA、字体、场景语义和可选人物同声源证明。只有脚本＋素材：先走项目音频中心/字幕阶段，按本期已选服务报价、预算和原operation恢复，取得实际WAV/词时码后进入同一个模板输入；不估计时长或匀分字幕。

脚本固定调用见[脚本制片契约](../../Haike_video/docs/DARK_FULL_SCRIPT.md)。新增制作前按模板手册检查工程卷/缓存卷实际余量；本次透明NTFS压缩保留全部作品逻辑字节、注册路径和旧版本，不等于后续可无限续产，也不以搬走注册原作或目录联接代替容量检查。

## 操作契约

| input → action | output与完成门禁 | recovery |
| --- | --- | --- |
| 本期完整输入 → `Haike_video/scripts/dark_full.py --input <input.json> --check` | 样本时钟、最小完整组、素材真实区间、同声源人物、字体字宽全部通过；只读，无云调用 | 补缺项或按语义重选整组；不能拉伸语音、循环短素材或切掉组尾 |
| 已确定开发输入/ready复用输入 → 同CLI不带check，或工作台“完整多屏模板”冻结并提交 | 唯一冻结请求、统一queue、实际候选成片与作品版本 | 按原 `--request` 恢复；相同输入幂等，忙时保留原暂停任务，不另造队列 |
| 经实际预览审核的官方native工程 → `Haike_video/scripts/dark_native.py --input <manifest.json>` | 原生十组、原顺序、122.4秒完整新渲染；替代内嵌素材与差异清单；原混合音轨只合入一次 | 公开helper原任务和永久实例内输出恢复；不改保护实现，不把下载预览冒称新渲染 |
| 实际编码视频 → 全解码/技术/关键状态与语义复核 | 画幅、帧数、20Mbps、AAC真峰值≤−1.5dBTP；视觉、听音、口型、平台、用户各自结论 | 只修受影响槽/本地合成阶段；保留原配音、人物和历史成片 |

## 固定与可换

内容槽、真实素材、口播、字幕、人物模式和BGM/SFX可换；设计骨架、层级、原速主时钟和整组动作依赖由版本源码固定。高级cue只改变启动点，不把整个动画快放。s02须接同一主素材连续时钟的s03。原版全十组与30秒精选组分开验收。

下一份新包先登记公开契约、完整状态、素材槽与布局，再做一次适配并真实试镜；完成适配后的换素材复用不改renderer。不是任意`.motion`零适配编译器。适配规范在模板手册末节。

## 交付与边界

交付可直接观看页面、完整对照、海客两片、可复制草稿、源码/规格/来源及本期回执。个人MotionGit包、缓存、系统/个人字体和凭据不放入公开源码。默认只生成待观看作品，本呼叫不授权平台发布。
