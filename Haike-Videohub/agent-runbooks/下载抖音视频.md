## 触发条件与输入

- 用户说“下载抖音视频”并给出链接时，优先走本入口，复用项目能力。
- 确认多仓布局为 `<工作区>/copy_skill/copy_skill-main/`；默认 Cookie 自动定位到 `<工作区>/www.douyin.com_cookies.txt`，不依赖启动时的当前目录。
- 用户指定 Cookie 文件时，传 `--cookies`；它优先于默认文件。支持 Netscape 格式，包括 `#HttpOnly_` 行；只读取未过期的抖音域 Cookie。不把文件内容放进聊天、日志或命令行参数。
- 用 MediaCrawler 隔离环境的 Python 执行。需要其现有依赖、系统 Chrome 和签名依赖 Node。不要用不具备依赖的任意 Python 替代。
- 核对用户是否需要新下载；此入口每次真实执行都创建唯一目录，不复用同名缓存，也不覆盖旧文件。

## 当前操作

以下 PowerShell 命令从工作区根目录执行；`$link` 替换为用户输入。

```powershell
$py = '.\copy_skill\copy_skill-main\third_party\MediaCrawler\.venv\Scripts\python.exe'
$entry = '.\copy_skill\copy_skill-main\scripts\download_douyin_mediacrawler.py'
$link = '用户提供的抖音链接'

# 离线检查：只验证输入和 Cookie，不启动浏览器、不下载、不创建交付文件。
& $py $entry $link --check

# 默认：使用工作区最上层 Cookie，下载到当前用户 Downloads。
& $py $entry $link
```

用户指定 Cookie 或输出目录时：

```powershell
& $py $entry $link --cookies 'D:\用户指定目录\douyin.txt' --output-dir 'D:\用户指定下载目录' --check
& $py $entry $link --cookies 'D:\用户指定目录\douyin.txt' --output-dir 'D:\用户指定下载目录'
```

1. 离线检查应返回 `status=input_ok`。这仅证明可解析出未过期 Cookie，不证明服务器接受当前会话。
2. 实际执行在独立、临时、无界面的 Chrome 上下文注入 Cookie；通过 MediaCrawler 解析短链接、签名请求和视频详情，再调用项目 `materials.download_video()` 下载。不会接管现有 CDP 浏览器；上下文结束即关闭。
3. 不需要启用上游 `ENABLE_GET_MEIDAS`。该开关控制上游自带媒体落盘，本入口直接调用项目下载函数。也不调用 yt-dlp、不运行关键词搜索、评论采集或素材筛选。
4. 解析阶段限时 120 秒；媒体请求超时 60 秒、单次尝试、上限 500 MiB。失败报告仅含阶段和异常类型，不输出原始响应、Cookie 或签名 URL。
5. 成功返回 `status=downloaded`，输出目录为 `douyin-<ID>-<时间>-<随机后缀>`，含 `<ID>.mp4` 和 `download.json`。回执仅记录安全元数据和文件校验值，不代表已经通过完整媒体解码。
6. 读取回执确认标题和编号，按 `file` 核对文件，再使用已安装的 FFprobe/FFmpeg 验证：

```powershell
# $file 来自本次 download.json 的 file 字段；工具不在 PATH 时使用项目配置中的绝对路径。
ffprobe -v error -show_entries format=duration,size:stream=codec_name,codec_type,width,height -of json $file
ffmpeg -v error -i $file -f null -
Get-FileHash -LiteralPath $file -Algorithm SHA256
```

只有进程成功、回执匹配、视频能解码，才向用户交付本次 MP4 的绝对路径。不要把旧的 yt-dlp 文件当成本次实测结果。

## 已知故障与安全恢复

| 现象 | 判断依据 | 当前安全恢复点 |
|---|---|---|
| `cookies` 阶段失败 | 文件缺失、格式错误或无未过期抖音 Cookie | 核对默认位置或用户指定路径；必要时请用户提供新导出。不要显示文件内容 |
| `mediacrawler_resolve` 阶段失败 | 依赖、Chrome、网络、短链、签名、平台会话或视频权限问题 | 先核对隔离 Python、Chrome、Node 和目标视频可见性；若需登录/验证，由用户处理。仅凭异常类型不能断言是 Cookie 失效 |
| `project_download` 阶段失败 | CDN、过期直链、大小限制、磁盘或下载异常 | 保留本次失败目录用于定位；确认原因后重新解析再下载，不手工保存/复用签名 URL，不无限重试 |
| MP4 存在但媒体验收失败 | ffprobe 无有效视频流或 FFmpeg 解码报错 | 不标成功；按本次编号定位，修正问题后再下载，不用旧文件替代 |
| 输出 MSVC 预加载警告 | 公共包初始化提示；本次实测中未影响下载和解码 | 以退出码、回执和媒体验收为准；若出现原生依赖崩溃，再按所属项目环境文档处理 |
