## 触发条件与输入

- 用户要求复用本次数字人口播效果时，直接采用 V1，不重新自由设计版式。用户另有指定时优先执行。
- 读取本期口播稿、预计时长、项目当前数字人/配音、音乐库和既有任务。只做分析不进入采集或渲染；已授权制片则持续完成必要环节。

## 当前操作

### 1. 口播与画面计划

压缩重复解释，保留钩子、核心事实、具体演示和结尾。文案每段对应明确画面目标：产品标识、真实操作、官方宣传片、代表人物演讲或必要图解。先建立段落—画面目标—候选素材—最终区间的对应关系。

“前 30 秒保留原稿”是单期约束，不是默认规则。开头第一帧应能识别主题，优先产品 Logo/界面；前三秒加入有信息的真实动态素材，避免只切渲染背景。已验证案例是产品图约 0.7 秒接官方动态素材约 2.3 秒，下一期可按口播调整节奏，不强行套同一源片。

### 2. 官方素材优先采集

优先顺序：产品官网/媒体包的 Logo、界面和官方演示 → 官方宣传短片 → 与本段主题有关的官方发布会/代表人物演讲 → 可核验的第三方补充素材。演讲画面需要与论点有关，不能仅凭人物知名度替代产品展示。

使用当前 CopySkill 采集入口及其规范；采集工具负责获取，选材仍需人工/视觉证据判断。先核对产品的准确名称、所属公司和官方域名；从官网向官方账号或下载资源追溯。优先干净原文件，拒绝无关科技 B-roll、带他人字幕/水印的二次剪辑。没有合适动态素材时报告缺口，不假称静态渲染为产品演示。

每个候选记录：asset_id、原始页面/下载 URL、官方身份依据、文件哈希、尺寸/时长、选用区间、对应口播、使用范围/权利状态。官方来源不自动等于任意用途授权。正式素材移入本期项目并登记；手册不收媒体或 Cookie。

下载预算按**预计成片时长**设初始软预算：≤30 秒 200 MB；30–60 秒 400 MB；>60 秒 600 MB。600 MB 为每期默认规划上限，统计本期新下载的源素材，不包含本地复用、渲染中间文件。此分档是采纳的操作策略，尚未证明是最优值，也未实现成全局硬限制；若官方唯一高价值文件超额，先依据用户已有预算权限调整或给出具体缺口。优先按需取片段、去重，够用即停，不能为了达到预算下载无关素材。

### 3. 固定布局，按期替换内容

使用版本化 JSON 作唯一参数真值，生成的坐标图便于检查，实际视频帧作验收证据；三者共同保存，不能只留一句“右上角”。

V1：顶部 15%（288px）仅背景；圆框左上角 (691,307)、直径 236px；标题绘制点 (125,420)、68px；素材卡 (110,625,690,620)；字幕测试绘制 y=1342、48px、最大实际宽度 700px。精确锚点、描边和字体见实现文档。该安全边距是本项目设计，不是抖音官方保证。

数字人的位置与脸部裁切分别记录。使用项目当前选定形象，核查第一人称手机自拍视角、头顶与下巴、眼神、源视频动作；换人物不能照抄上一个人的 face_crop。圆框位置固定，不为每张脸移动整个版式。标题太长先精简；字幕太长先按语义拆句。

### 4. 小样验证后复用

按模板 CLI 的 episode spec 生成三秒测试及 manifest；检查第一帧、真实动态片段、人物圆框与字幕，再叠加平台 UI 检查。首次模板或重大布局变更需要看样；同一已确认模板的下一期直接复用，仍做新文案/新人物的技术与遮挡检查，不反复请求相同审批。

UI QA 至少含顶部状态/导航/搜索、右侧头像/赞/评论/收藏/分享、底部作者/描述/音乐/导航。按目标截图的真实内容视口换算视频的 contain/cover/裁切；可另做更苛刻的居中裁切压力图，并标记为模拟。不要直接把手机整屏尺寸当成视频画布。蒙版与按钮只留在 QA 图中，不进入正式视频。

### 5. 音频、字幕与正式生产

本次“檬檬 + 顶级智斗感”的用户确认参数是 **BGM 播放增益 -9 dB**；不是 -9 LUFS，也不是所有音乐统一标准。下次沿用相同组合可作为起点；换音乐/人声则检查听感、语音清晰度、真峰值和限幅情况。已经混好的音轨不得再降一次 -9 dB。不能把用户观察到的平台处理当作平台恒定规则。

样板也应展示字幕，正式视频必须完整逐句同步。按实现文档把背景资产、人物布局和字幕样式接入工作台；样板的单句烧字不能延用到整片。复用现有配音/人物 master，纯版式修改不触发付费数字人重生成。全片预览仍走统一队列，预览与成片共用配置；完整预览人工确认后，按当前正式合成闸门交付。

### 6. 完成与发布交接

交付成片、封面、标题、详情和话题；是否上传依用户授权，用户手动发布就交付材料。检查所有场景的标题、字幕、人物和重要产品信息，包括最长文案、转场和结尾，不以开头通过替代全片通过。

本地播放器通过之外，区分「模拟 UI 通过」与「真实手机平台播放通过」。发生过真实遮挡的旧布局已由用户截图确认；新布局目前只确认三秒测试。下一次有实际播放证据后，记录设备/视口/页面及遮挡结果。按[三平台发布](短视频三平台发布.md)执行，不为验收擅自上传、重复发布或删除作品。

## 已知故障与安全恢复

| 现象 | 判断依据 | 当前安全恢复点 |
|---|---|---|
| 搜索/导航挡脸，右侧按钮挡产品 | 实际播放截图或带 UI 的证据图 | 检查视口映射、顶部余量及圆框边界；修改配置版本后先出三秒样板 |
| 材料很多但主题无关 | 对不上段落画面目标 | 回到产品官网/官方演示和最终源区间，不用下载量替代覆盖率 |
| Logo、小字、操作被裁掉 | 源图与成片 crop 对照 | 重构该素材卡/预处理，保持外部版式；重新检查该区间 |
| 字幕缺失、溢出或样板与全片位置不同 | 字幕时轴、实际字框、渲染 anchor | 补逐句字幕，按实际输出对齐；Pillow 与 ASS 坐标不能直接等同 |
| 音乐样板长期 generating | 任务、日志和实际 producer 状态 | 检查是否只写状态却未启动生成；沿现有 API/队列恢复，不手改完成标记 |
| 改位置却准备重生数字人 | 已有可用 master 与本次改动范围 | 复用付费产物，只更新布局/素材及预览；先查同类活动任务 |
