## 触发、规格与前置条件

- 稳定呼叫名为「数字人模板7」，可识别「数字人口播模板7」。明确呼叫时读取本手册及规格，不套用模板6招商或通用圆框布局。
- `template_id=avatar-interview-v7`，规格版本 `v001`；初始为 `implementation + specification`。用户本次明确委托创建新 runbook，属于本次正式编写范围，直接完成规格和开发测试。
- 启用 `avatar`、`graphic`、`material_edit` 及 `interview_v7` 扩展；按[视频模板编写标准](视频模板编写标准.md)、[类型扩展](template-standards/类型扩展.md)和[验收量表](视频模板验收量表.md)记录。
- 布局、色板、字号、裁切窗口、遮罩和动效参数真值为 `layout.json`；图层组件、显隐与求值顺序真值为 `Composition.tsx/Captions.tsx`。本期文字、媒体和切点来自冻结 manifest。规格的名义布局包络用于验收定位，不是第二套渲染配置。
- 当前执行入口是本地 Atelier 开发短样 CLI，输出测试文件。尚未接通 Studio 模板目录、草稿表单、统一生产队列、作品登记或完整生产 API，不能把独立渲染当作生产接入通过。
- 本次输出为 1080×1920、30fps、19.0 秒/570 帧。声音为原片同钟连续选段，主窗素材和独立圆人物是静音视觉源；不拉伸语音、不新增 BGM、不调用 TTS、ASR 或数字人云服务。
- 本期四段主窗均 `fit=contain`；前景完整保留有效素材内文字，下层同源同入点 cover 视频按 `layout.main_contain_background` 模糊、降亮和放大填满主窗。前景、背景是独立视频图层，仅 contain 时启用背景，cover 模式不叠加该层。
- 最终输出必须经过 CLI 的 `audio_clock_mux="master_wav_v1"`：Atelier 原生输出后，以冻结同钟 WAV 重新 AAC 封装，视频 `-c:v copy`，本期 `-t19`；用同目录临时 MP4 完成后原子替换。该步骤修复原生编码音轨的 2048-sample 延迟；数值时钟检查不能替代连续听辨。
- 必需本期输入为 manifest 和可解码本地媒体；媒体路径相对 manifest 所在目录解析。项目目录必须是本 checkout 的 `.local/`、`Haike_video/projects/` 或 `Haike_video/.backlot/` 子目录。预检要求布局声明的字体可用，使用 `font_path` 时须保持同一字体身份并重新核验。素材、人物与音轨使用范围保持本次本地分析及开发测试，公开发布另需实际来源及本次发布授权。
- 先读 [Haike_video 入口](../../Haike_video/AGENTS.md) 及当前 Guide，核对本次工作区、实现 SHA、manifest、媒体来源和已有产物。14754 安装副本与当前源码 checkout 的运行数据不得混用。

## 参考拆解与重建范围

根任务执行者实际查看了 8 张概览图、72 张抽样帧，覆盖约 0.033..261.1 秒，另查看 6.567 秒原尺寸帧。参考文件约 261.55 秒、1080×1920、30fps；这是离散视觉结构证据，没有因此声称完整连续听看。

参考的稳定结构是黑色星点顶区与两行白色粗标题、蓝青分割、中部人物/素材主窗、顶部双胶囊、白字深描边斜字幕、右下圆人物，以及深紫品牌底区。后半段出现大编号和红黄关键词。具体坐标来自画面估读，当前实现的确定数值只读布局真值。

参考底部作者姓名、人物形象、账号标识以及“AI 合成”等文字属于原片固化内容。画面只证明它作出相应宣称，不能据此断言人物是真人或数字人、作者真实身份、使用的软件、全部素材出处或商业事实。本次重建底板和编辑文字，使用“数字人模板7／结构复刻测试”等开发内容，不复用旧作者底板或身份作为新品牌。

本次人物与素材裁切来自用户提供的原片局部，是开发测试媒体，不能称为新生成的数字人。选段中的原画面固化关键词仍属于源素材；可编辑的模板 focus/字幕与这些固化内容分别登记。参考原有全片论述不因本地结构复刻而完成事实核验。

本期接受的设计偏离是完整保留 978×550 有效素材区及其固化文字。参考为已合成画面，无法无损恢复独立净 B-roll；此前 cover 前景会侧裁原文字，现改 contain 前景，并用同源模糊背景填满主窗。素材在样片约 9.2 秒含源自带短黑场过渡，根任务已实际对照源 broll 帧；保留该过渡，不将它误判为 render 缺素材。精确持续范围以本期源帧记录为准。

CLI 使用 UTF-8 JSON manifest；实际字段校验以本期源码预检为准：

| 字段 | 输入与边界 |
|---|---|
| `duration_seconds` | 15..25 秒；本期固定 19.0，独立音轨同长 |
| `media` | `avatar`、`audio` 及启用 broll 时的 `broll`；`avatar_pip` 为独立圆人源。本期各项均来自来源记录中的同钟原片片段 |
| `title_lines` | 1..2 行非空主题文字，本期两行；可选 `title_emphasis` 标记原文中需强调的子串 |
| `brand`、`tagline` | 本期品牌字符串与不超过两行的 tagline 数组；本期标明模板名称和结构测试 |
| `context_pill`、`source_pill` | 主窗顶部上下文与准确来源说明；当前缺省值/长度以 CLI 为准 |
| `footer_note` | 底部本期结构测试说明；缺失时采用 CLI 明确默认值 |
| `development_label` | 开发样片及来源范围标记，不能改成已发布或新生成数字人的宣称 |
| `scenes[]` | `id,start,end,mode`；`mode=presenter|broll`。全片秒左闭右开且连续铺满；`source_in/avatar_in/pip_in` 为各源局部秒。本期四段均 `fit=contain`，同源模糊背景按当前实现自动启用；cover 模式能力未在本期前景采用 |
| `scenes[].summary` | 可选 `kicker,title,body`；本次未启用，不能记为已验收 |
| `scenes[].focus` | 可选 `value,label` 及当前实现允许的颜色选择；重点依据本期确定的 scene 时钟，不编造 ASR 匹配结果 |
| `cues[]` | `start,end,text` 为全片秒与真实对应文本；不重叠、不越片尾，CLI 归一化为 Caption 毫秒 |

本次来源裁切、准确坐标、音频样本数与 SHA 以媒体 `provenance.json` 及冻结输入记录为准；实际媒体在本期 `.local` 忽略目录。旧固定标题、胶囊、圆框旧字幕及底板不得混入新模板的编辑层。独立圆人物源避免大裁切带入原烧入字幕。

## 当前操作

### 1. 核对与冻结输入

- `input`：本规格、当前模板源码/layout、用户指定的本地来源、本期 manifest、媒体及已有项目记录。
- `action`：在 `Haike_video` 运行 `python scripts/avatar_template7_sample.py --manifest <本期JSON路径> --project <本期忽略项目目录>`，默认仅本地预检和准备；读回 probe、字宽/行数、时间/源长度校验及冻结身份。
- `output`：冻结 manifest、媒体与源码 SHA、准备回执、项目目录和已有产物复用结论。
- `gate`：必需媒体可解码且时长足够；scene/cue 合法；所有文字在当前字宽与最小字号范围内；本次只复用已有局部声画且没有付费或发布动作；现有输出先核对身份。
- `recovery`：缺失项补同一输入；时间或字宽失败定位到原字段调整。已有完成产物保留，不重新生成数字人、转写或配音。

### 2. 生成本地开发短样

- `input`：同一准备通过的 manifest 与项目、当前实现身份、本次 19 秒确定参数和开发测试授权。
- `action`：同一 CLI 增加 `--render`；先走本地 Atelier 的 `VideoCompose.execute`，再由同一 canonical CLI 固定执行原 WAV 重封装。实际映射为 `-map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -t19`，完成临时 MP4 后原子替换。可用 `--concurrency` 控制本地渲染并发；仅明确更新本地冻结输入时按 CLI 保护规则使用 `--force`。
- `output`：fingerprint 命名的 canonical 开发 MP4，以及项目 `artifacts/` 中的 `props.json`、`edit_decisions.json`、`sample-state.json`、`composition-preflight-result.json`、`native-render-result.json`、`sample-evidence.json`；最终状态/证据必须读回 `audio_clock_mux="master_wav_v1"` 和 `audio_clock_audio_sha256`，后者等于冻结原 WAV SHA。
- `gate`：最终文件对应同一冻结输入且 master_wav_v1 回执齐备。本期覆盖四段 contain 完整前景、同源模糊背景、独立圆人、自定义标题/品牌、双胶囊、手工 cue，以及编号 1/2 与黄色描边关键词。red、全幅人物及可选摘要卡未覆盖；约 9.2 秒源短黑场保留。编号半透明，关键词无卡片底板。退出 0 或 `native_render_completed` 不能代替最终技术、实际视觉或连续听辨。
- `recovery`：先读同一项目回执与已有输出 SHA。已 `native_render_completed` 且输出可核对、尚缺 master_wav_v1 时，只恢复原 WAV 重封装，不重新渲染视频；最终成功缓存须核对 mux 标志和音轨 SHA。仅布局/文字问题才复用媒体本地重渲染，不扩大为正式生产或重新调用云服务。

### 3. 验收并交付测试产物

- `input`：最终 MP4、同一 manifest/layout/源码身份、媒体来源及技术/帧证据。
- `action`：对最终 master_wav_v1 文件完整解码，ffprobe 核对尺寸、帧率、19 秒/570 帧及音轨，读回冻结 WAV SHA，并独立做数值延迟/时钟检查。实际查看所有 contain 前景文字、同源模糊背景、最长字幕、圆人、双胶囊、标题/品牌底区、编号 1/2 与黄色关键词、进出点和尾帧；约 9.2 秒黑帧对照原生源过渡。连续听看、真机、用户确认单独取得实际证据，数值相关性不升级听辨状态。
- `output`：最终 SHA、技术报告、实际帧及七维矩阵；通过可点击文件清楚交付本地测试产物。
- `gate`：所有适用项有结论，失败项已修复或明确阻断对应声明。静态检查不能代替画面，抽帧不能代替听看，测试文件不能代替工作台生产/作品记录。
- `recovery`：按元素与时间段定位；复用原声画修正本地版式。最终 SHA 改变后更新受影响证据，不沿用旧审核结果。

### 4. 正式生产接入的停点

本 runbook 当前没有正式全片执行步骤。后续采用新人物/新稿件/真实生成时，先确定来源、音轨、服务能力与费用授权，完成当前模板参数的受控映射和统一队列/作品接入，再做对应全片技术、视觉与听看验收。当前独立 Atelier 短样不升级 `production`，不允许通过直接调用注册生产 runner 绕开队列。
