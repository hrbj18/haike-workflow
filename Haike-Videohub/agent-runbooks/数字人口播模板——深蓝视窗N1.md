## 四种主窗模式

| 模式 | 主窗画面 | 下圆框与字幕 | 适配/裁切要求 |
|---|---|---|---|
| 主持人 | 清晰人物居中，两侧同源模糊延展；固定圆角窗 | 下圆框隐藏；主字幕照常 | 等比保留头、下巴与必要手势；清晰人物不横向拉伸，模糊两侧使用同一来源 |
| 素材 | 展场、产品、道路或其他本期画面；可满窗、留黑边或模糊延展 | 下圆框显示；主字幕叠最上 | 按源比例选cover/contain/同源背景。参考FRAME24/25为满窗，FRAME9/50为上模糊下清晰，FRAME23为上黑下横幅；不统一使用cover |
| 截图 | 来源截图完整或按引用区间裁切，可叠红线 | 下圆框显示；主字幕保留 | 保留引文、必要上下文和来源；截图原有文字与主字幕分别检查，红线绑定截图坐标 |
| 数据板 | 深蓝底，顶部黄标签、白标题、黄色方块加四行白文本 | 下圆框显示；主字幕保留 | 采用纵向列表，允许先铺出后静持；数据内容和行数按本期替换，不固定原片数字 |

截图与数据板是N1要求的视觉状态。模板4目前的 `stages.kind` 仅为 `presenter/video/diagram`，其中 `diagram` 是横向节点卡，不能直接当作本片四行数据板；使用静态媒体或新增组件时在本期保存明确映射并出样片核验。

视觉模式由本期画面安排控制，不要求照抄原片主持人回场顺序。已见主窗主持人时圆框隐藏、其他三模式圆框显示；切换瞬间也需检查这一互斥关系。

## 入场与文字动效

- **固定标题壳**：三行主题标题贯穿主体画面；片头黄主标题有渐显证据，具体透明度曲线、持续时间与精确切点未知。保留主窗/背景连续呈现，只控制本期主标题入场。
- **数据铺出**：局部2fps标签64.5、65、65.5、66秒样本相继见到四行，随后保持，由字幕逐项解释。实际入场间隔尚未逐帧测定，不能把0.5秒采样间隔写成动画时长。忠实起点是「快速先后铺出→静持」，按音频逐行同步属于待验证优化。
- **截图高亮**：样本见红线分阶段变长并新增第二条；显示事件绑定截图和本期引文，不照抄历史秒数。
- **字幕重点**：句内指定字/词静态呈暖黄，其他字为白色，整句切换时换文本；没有逐字跟读或卡拉OK证据。关键词字段不代表ASR词级时间戳。
- **模式转换**：同一主窗内换内容，外壳坐标保持稳定；下圆框按模式显隐，人物与音轨共享本期时间轴。
- **采样边界**：局部标签来自起点加序号/采样率，不是逐帧PTS。本轮只证明这些视觉变化顺序，不证明已听辨同步或精确原工程动效。

模板4的 `introSeconds` 当前创建全屏封面（既有样片0.6秒），与N1片头主标题渐显不同；复刻N1时应调整对应入场方式，而不是直接沿用旧全屏封面。

1. **锁定参考与本期输入。** 读生产入口，核对素材/人物/字幕、已有任务、本期授权及目标尺寸。完成条件：画面来源和同一声画时钟明确，编号N1只对应本视觉手册。

3. **实现四模式与独立叠层。** 可在模板4正式源码的本期副本起步；补齐数据纵列、截图高亮/贴纸、胶囊样式、标题入场和避让配置。人物/素材视觉层静音，主音轨单独播放一次。完成条件：四模式、圆框互斥与字幕叠放都有实际输出，缺少适配时仍标实现待验证。
4. **出代表性短样并看原尺寸帧。** 覆盖主标题渐显、主持人同源模糊两侧、满窗/留边素材、带贴纸素材、截图两条红线、四行数据铺出/静持、最长字幕/品牌、模式切换和收尾。完成条件：所有应显示图层均有版本一致的短样与帧证据，画面布局和避让经用户确认后冻结。
5. **逐项完成视觉QA。** 核对上表各层锚点、圆角/比例、暖黄/蓝背景、标题和来源字宽、窗内字幕/静态重点、人物裁切、圆框显隐、胶囊细边/渐变、淡英文裁切、底线与贴纸/红线。对照完整状态、最长文案和每次切换，不以存在原片遮挡作为本期通过理由。完成条件：无阻断性缺图、拉伸、切头、字幕或引用遮挡；忠实版与优化版身份分开。
6. **全片与平台验收。** 正式生产按生产入口进入工作台/统一队列；核对输出编码、fps/帧数、流/容器时长、完整解码、manifest和QA对应同一版本。连续观看和回听检查事件、口型、字幕及音轨；目标平台检查实际内容视口内的顶部/右侧/底部UI遮挡。完成条件：技术、视觉、听看、用户确认、平台读回分别记录；缺项保持待验证，交付待审视频，发布另循本次授权。

## 已知限制与安全恢复

| 现象 | 判断依据 | 当前恢复点 |
|---|---|---|
| 把字形框当字号或CSS top | 渲染字宽、基线和参考可见边界不一致 | 使用真实字体测宽/排版，重看原尺寸帧 |
| 主持人拉伸或模糊两侧异源 | 清晰人物比例与源帧，适配配置 | 保持等比清晰层，背景改用同一来源扩展 |
| 所有素材统一cover导致截图/产品被裁 | 源比例和最终主窗 | 分别选contain、同源模糊或可证明完整的裁切 |
| 原素材内字与主字幕重叠 | 源文字边界与本期最长cues | 调整字幕/前景适配或采用无字区间，保存避让参数 |
| 主窗人物与下圆框同时出现 | 四模式和显隐条件 | 修正模式互斥，复用可用人物局部重出 |
| 胶囊变粗白边黑底、数据变横卡 | 实际输出与N1测量表 | 修正本期组件；不因模板4已有组件而判为忠实复刻 |
| 红线/贴纸漂移或覆盖主字幕 | 截图坐标、显示事件和z序 | 绑定模式与内容坐标，字幕保持上层并重验完整状态 |
| 把2fps间隔当动画时长 | 请求标签与逐帧证据范围 | 保留变化顺序，需精确时长时再补逐帧取证 |
| 顶部/品牌/英文/圆框被平台UI挡住 | 目标入口真机视口 | 保存平台变体并重新读回，不推断通用安全区 |
| 只有视觉规格，没有N1样片 | 产物、实现版本和QA缺失 | 从适配/短样继续，保持实现和生产待验证 |
