## 触发条件与输入

- 用户要求复用「数字人口播模板2」版式时，直接采用本参数，不重新自由设计；用户另有指定时优先执行。
- 输入：本期口播稿、素材片段、项目目录。配音默认用工作台当前默认音色（百炼复刻音色；音色记录只存本机配音中心与脚本参数，手册不记录 ID）。
- 开始前先查项目已有样板、测试片、全片产物与在途任务；相同输入的成功产物直接复用，不重复提交云端生成。
- 云端付费点：克隆音色 TTS（按字符）、ASR 对齐（按量）、数字人分段生成（按量）。改版式或字幕不动数字人；改文案只重做受影响段落。

## 当前操作

命令均在 Haike_video 根目录用项目环境（`.venv/Scripts/python.exe`）执行；脚本内部使用绝对路径。

### 1. 版式参数（1080×1920，v4 定稿）

参数集中在 make_mockup.py 顶部 dict；改版式先出静态样板图（`python make_mockup.py v4`）给用户确认，再进视频。

| 元素 | v4 参数 |
|---|---|
| 标题 | 「新世代宝马i3」76px 白 (250,253,255)，绘制点 (125,330)；bbox 右缘断言 ≤620，防撞数字人 |
| 副标题 | 「全面破局」56px 青 (30,171,221)，x=125，视觉间距 30px 自动跟随标题下缘 |
| 数字人 | 340px 圆 @(650,292)，圆环 5px 青色；face crop 242×242@(102,156)（448×560 母版） |
| 视频带 | 全宽 1080×608 @(0,660)；源片 1920×1080 裁 1492×840 @(214,115) |
| 字幕 | 56px 白字、描边 5 (3,9,20)、居中绘制 y=1292、安全宽 ≤900、无标点 |

- 顶部 288px 为导航保留区，标题组继续上移受此约束；视频带右缘伸入右侧按钮栏区域，真机遮挡待验。
- 视频带裁剪须避开源片顶部「辅助驾驶」标签（y≤107）与底部烧录字幕（y≥约 965）；换新源片先看代表帧重新定裁剪窗口，不沿用区间。
- 数字人圆框位置固定，不因换脸移动版式；换人物先核对 face_crop 再进付费生成。

### 2. 配音与字幕计时（克隆音色）

1. TTS：`backlot/tts_runtime.generate_voice_audio(profile=…)`，默认音色 = 百炼复刻音色（cosyvoice-v3.5-flash，语速 1.0）；独立脚本必须先 `load_env(HOME)`（lib/env_loader），否则报缺密钥。按字符计费。
2. ASR 词级对齐：`backlot/bailian_asr.transcribe_file`（qwen-audio-3.1-asr-flash-filetrans，词级秒制时间戳）。克隆音色不返回逐字时间戳，字幕计时以 ASR 为准；任务记录与缓存不得删除，避免重复计费。
3. 分句与去标点：按标点断句，字幕不保留标点；行首标点归并到上一句；超宽再按宽度自适应二次切分（目标 ≤12 中文字、安全宽 ≤700px，不在 Momenta 等 ASCII 串内部断开）。
4. 渲染字幕 PNG：56px／描边 5／绘制点 y=1292 居中；空白 token 不产生 cue。
5. 当前入口：`python build_5s_clone_test.py tts|asr|cues|video`；全片重制时把该管线的分句/渲染参数与 gen_subtitles.py 的时间轴逻辑合并改写。

### 3. 合成与验收

- 扁平合成（与已验收 5 秒测试片同源滤镜链；全片按本节参数改写）：背景 PNG ＋ 素材带 `crop=1492:840:214:115,scale=1080:608` ＋ 数字人 `crop=242:242:102:156,scale=340:340,setsar=1,eq=brightness=0.035:contrast=1.060:gamma=1.040,geq 圆形 alpha` @(650,292) ＋ 字幕 PNG `overlay enable=between(t,begin,end)` ＋ VO 音轨；输出 1080×1920/30fps、H.264 crf18＋AAC 192k。
- 验收：全片解码、帧数与时长；逐句字幕（时间、宽度、无标点、不重叠）；标题与数字人不碰撞；素材带四缘无源片标签与烧录字幕。
- 只在获授权后按[短视频三平台发布](短视频三平台发布.md)发布；遮挡验收区分「模拟 UI 通过」与「真实手机播放通过」。

## 已知故障与安全恢复

| 现象 | 判断依据 | 当前安全恢复点 |
|---|---|---|
| 视频带露出源片顶部标签或底部烧录字幕 | 代表帧边缘出现「辅助驾驶」条或原字幕 | 按 crop 214,115,1706,955 核对收窄；换新源片重做边缘检查 |
| ASR 报「请先保存阿里云百炼 API Key」而 TTS 正常 | 报错文本；TTS 导入链会加载密钥、ASR 链不会 | 脚本顶部先 `load_env(HOME)` 再调用；不重复提交任务 |
| 字幕超宽、行首标点、空字幕 | cue 宽度与文本检查 | SOFT_MAX=12＋宽度自适应二次切分；行首标点归并上一句；过滤空白 token |
| 相邻字幕重叠 | 后一句 begin 早于前一句 end | 后一句 begin 取自身起点与前句 end＋0.04s 的较大值 |
| 云端任务疑似重复提交 | state 为 submitting 且无供应商任务 ID | 先查项目 .bailian 记录与 ASR 任务缓存；未排除已创建前不重发、不删记录 |
| 标题与数字人过近 | 样板 bbox 越界断言 | 维持 assert tb[2] ≤ 620；先精简文案再动几何 |
| 仅改版式却准备重跑数字人 | 改动范围仅为布局/字幕/配音 | 复用已付费数字人 master 与素材；仅配音变化时才按需重生成 |
