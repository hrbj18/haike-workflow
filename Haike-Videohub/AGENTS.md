# Videohub Agent 入口

按任务读取需要的文档：首次部署和跨仓配置从 `AGENT_SETUP.md` 开始；日常可重复操作先读 `agent-runbooks/README.md` 索引、匹配手册及相关 `contracts/`。制片任务还须遵循 `../Haike_video/AGENTS.md`。手册中的旧路径、任务 ID 和界面状态只是案例，执行前核对用户本次授权与实时状态。

用户明确说「模板图文视频」时，直接读取 `agent-runbooks/模板图文视频.md`；这个同名呼叫优先于通用视频类型推断，不得改走窗口复刻、素材复刻或通用 Codex 原生制片。

用户明确说「数字人口播模板3」「数字人口播视频模板3」或「数字人口播模板3-卡片式讲解」时，优先读 `agent-runbooks/数字人口播模板3-卡片式讲解.md`；这是 3:4 卡片讲解样片基准，全片接入状态以该手册为准。

其他「数字人口播视频」「数字人口播模板」或复用圆框数字人加官方产品素材的版式，读 `agent-runbooks/数字人口播视频.md`；复用版本化布局配置，正式预览/合成仍走工作台队列。

用户要求下载指定抖音视频时，读取 `agent-runbooks/下载抖音视频.md`；使用项目内置入口及工作区顶层 Cookie，或用户指定的 Cookie 路径。

用户要求视频理解、快速分析、多宫格抽帧或参考片拆解时，先读 `../Haike_video/AGENTS.md`，再读 `agent-runbooks/视频快速理解与分层分析.md`；先概览、按需补证据，正式选材继续走项目 V2 和区间 QA。

完成实际操作后，若发现可复用的新步骤、恢复方法或旧步骤失效，按 `agent-runbooks/README.md` 提交发现与证据。默认只提案；用户明确委托维护知识库时，核对证据后才修改正式手册。替换旧结论、合并重复内容，未验证内容不得标「已实测」。普通问答和无新发现的重复操作无需修改；不要自动提交或合并其他 Agent 的提案。
